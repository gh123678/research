# 验证：新论文公式—代码对照表

## 1. 端到端 sampled-SARSA 构造

| 论文步骤 | 代码位置 | 核验方式 |
|---|---|---|
| 完整 prompt `H0=[Q-memory, transition, null]` | `verify_end_to_end_sarsa.py`, `build_literal_prompt` | fixture shape `[32,20]`，并断言每个 token coordinate |
| current head 的 `WQ,WK,WV,WO` 与完整 mask | 同上，`literal_end_to_end_sarsa` | 与直接 `Q(X_k)` 索引零误差，每个 mask row support 非空 |
| next head 的 `WQ,WK,WV,WO` 与完整 mask | 同上 | 与直接 `Q(X'_k)` 索引零误差，softmax row 有限且归一化 |
| 两单元 ReLU FFN 的 `W1,W2` | 同上 | 由原始 reward 与两个 retrieval scratch 精确形成 signed residual |
| write-back 的 `WQ,WK,WV,WO` 与 null routing | 同上 | 重复 pair 权重严格为 `1/n_x`，8 个未访问 pair 保持不变 |
| literal / compact / reference 完整 batch 更新 | `verify_end_to_end_sarsa.py` | literal-reference 与 literal-compact 最大误差均为 `5.55e-17` |
| singleton sequential 更新 | `verify_end_to_end_sarsa.py` | 6 步 literal/reference 最大误差 `2.78e-17` |
| finite retrieval/write-back 界 | `EndToEndFiniteSoftmaxSARSA` 与 verifier | 更新误差 `0.250 < 1.170` 界 |

这里的 literal verifier 才是完整 prompt 网络的 implementation witness。`evaluate_softmax_sarsa_control.py` 的大规模 sweep 直接索引两个 Q 值，只检验紧凑 residual/write-back kernel 与闭环控制表现；不能把后者写成完整 prompt 的端到端实验。

## 2. 两阶段主方法

| 论文公式 | 代码位置 | 核验方式 |
|---|---|---|
| `p_beta=softmax(beta Q)` | `model.py`, `GroupedSoftmaxMax.forward` | 权重沿动作维求和为 1 |
| `M_beta=sum p_beta Q` | `GroupedSoftmaxMax.forward` | 与显式加权和逐元素一致 |
| `0<=max Q-M_beta<=log|A|/beta` | `verify_two_stage_q_control.py`, `check_softmax_max_bound` | 128 by 7 随机 Q、多温度 |
| `delta=r+gamma M_beta-Q(s,a)` | `TwoStageSoftmaxQControl.forward` | diagnostics 返回 `td_values` |
| `K=softmax(eta psi_context psi_query^T)` | `KernelizedSoftmaxQTD.forward` | 每个查询列求和为 1 |
| `Q+=alpha sum K delta` | `KernelizedSoftmaxQTD.forward` | `(2,-3)` signed 测试与单位核极限 |
| internal/oracle 差距界 | `check_two_stage_oracle_gap` | 实际 0.010506 < 上界 0.064694 |

## 3. 第三篇对照

| 论文公式 | 代码位置 | 说明 |
|---|---|---|
| `delta=r+gamma phi_next^T w-phi^T w` | `LiangLaiOperatorBaseline.forward` | SARSA 型参数 residual |
| `Delta w=(alpha/n)Phi^T delta` | 同上 | 与显式公式达到浮点精度 |

这是 operator baseline，不声称复现 Liang–Lai 的 teacher-mimicking 训练动力学。

## 4. Oracle 与 external operations

| 运算 | 位置 | 是否主方法内部 |
|---|---|---|
| exact `amax` | `OracleMaxKernelQTD`、实验的 exact Q iteration | 否，仅 oracle |
| 环境动作 `argmax` | 评估指标 | 否，模拟器接口 |
| 期望转移 `sum P(...)` | `evaluate_two_stage_q_control.py`, `bellman_target` | 环境期望，用于隔离采样噪声 |
| action softmax-max | `GroupedSoftmaxMax` | 是 |
| signed kernel write-back | `KernelizedSoftmaxQTD` | 是 |

## 5. 旧类的新定位

| 类 | 实际机制 | 当前用途 |
|---|---|---|
| `SoftmaxEvalImproveV2` | max target 输入给定；delta 与 `Phi delta` 在 attention 后计算 | modular baseline |
| `SoftmaxEvalImproveV5` | 在 V2 后外部计算 `delta softmax(delta/tau) phi` | external TD-score ablation |
| `SoftmaxEvalImproveV4` | 直接用 attention 权重凸组合裸特征 | pure feature convex ablation |
| `SoftmaxEvalImproveV3` | 特定布局重建 `phi^T w` | protocol-specific diagnostic |
