## 3. 20-task 主实验

```bash
python evaluate_two_stage_q_control.py --tasks 20 --steps 200 --sweep-tasks 10 --sweep-steps 20
```

允许最后几位浮点差异。核心期望值：

| 方法 | Q infinity error |
|---|---:|
| exact Q iteration | 约 7.5e-13 |
| oracle-max kernel | 约 7.5e-13 |
| internal beta=1 | 约 0.247 |
| internal beta=5 | 约 0.0876 |
| internal beta=10 | 约 0.0344 |
| internal beta=20 | 约 0.0113 |
| pure-convex signed-free | 大于 100 |

通过标准：内部方法误差随 beta 总体下降；每个 max gap 小于对应理论界；oracle 达数值精度。
