## T1 历史条件、可测性与认证批独立性 —— PASS

对每格、每步 `k = 1..4` 列 `H_(k-1) = σ(MDP, train, B_1, …, B_(k-1))`：

1. **`Q̂_k` 与 `π_(k-1)` 是 `H_(k-1)` 可测的。** 两者只由 `train`、**初始策略**以及前 `k−1` 步的判决结果决定；判决结果又只由各自步的 `Q̂`、`E_Q`、`LB` 决定。归纳步无缺口。
2. **未读本步批。** 认证批由 `step_seed_parts(SEED, 90417, round(100·mixing), task_index, step)` 生成——**按 `step` 索引的独立随机流**，故 `B_k ⊥ H_(k-1)`。实现中 `raw` 的抽取写在 `q_hat` 计算之前（沿用基线控制流），但 `q_hat` 的计算**不读取 `raw`**；可测性依据是**计算依赖关系**，不是源码行的时间先后（此处与前两轮审阅的口径一致）。
3. **`Y_x` 是固定函数。** `Y_x = r + γ·V̂(s′) − Q̂(x)`，其中 `(π, Q̂)` 给定 `H_(k-1)` 后固定，故 `Y_x` 的**分布 `P_x` 固定**（行为策略只影响访问次数，不进入 `Y` 的分布）。
4. **首访样本在给定容量下 iid。** 每条独立链对每对只保留**首访**残差；引理 A' 已由独立审阅确认为真（`G_c` 由首访前轨迹决定、取值在首访处新鲜抽取，故 `Y_c ⊥ 1{G_c}`；条件于 `N_x = n` 样本为 `P_x^{⊗n}`）。
5. **风险积分与 union 的顺序正确。** **先**对每对的随机容量 `n` 取全期望（`N_x` 与取值独立，故无 union 代价），**再**对 `d = S·A` 个对做 union：`d·delta_dir = delta_step`。**不**条件化于"所有对联合通过"这一事件后再宣称 iid。
6. **未宣称的范围**：当前风险是**单条生产者-路线轨迹**级（`delta_total = 0.05`）；**不**声称 192 条路线记录或两生产者的联合保证。

## T2 `L12` 保证的是**幅值**界，不是中心区间 —— PASS

`L12` 输出标量 `ε_x = |mean_x| + radius_x`，`E_Q = max_x ε_x/(1−γ)`。所需命题是 `|ρ_x| ≤ |mean_x| + radius_x`。

证明按**真实、历史可测**的 `ρ_x` 符号分情况（`radius` 对 `Y → −Y` 不变）：
- `ρ_x ≥ 0`：只用 MP 的**上侧**方向 `ρ_x − mean_x ≤ r_x`，得 `|ρ_x| ≤ mean_x + r_x ≤ |mean_x| + r_x`；
- `ρ_x < 0`：只对 `−Y` 用 MP，得 `−ρ_x + mean_x ≤ r_x`，即 `|ρ_x| ≤ −mean_x + r_x ≤ |mean_x| + r_x`；
- `ρ_x = 0`：幅值上界平凡成立。

故每个**固定分布**只需 MP 的**一个方向**，`Pr{|ρ_x| > |mean_x| + r_x | H, n} ≤ delta_dir`，`d·delta_dir = delta_step`，跨步 union ≤ `delta_total`。

**明确不复用**"MP 双侧"的旧错误解释，**不**把幅值界写成中心区间 `|mean − ρ| ≤ r`；**不**额外声称所有记录/生产者的联合保证。口径：`delta_dir = delta_step/(S·A)`；`y_range = 2(R* + γ‖V̂‖∞ + ‖Q̂‖∞)`；`log_term = log(2/delta_dir)`；`ddof = 1`；`sqrt(2·var·log_term/n) + (7/3)·y_range·log_term/(n−1)`——与任务单 §3 逐项一致，且**不使用任何核**。

依据：`docs/derivations/FP-L12-one-sided-proof.md`（应第二轮审阅要求补写，经审阅方独立证明与交叉 PASS）。

## T3 按状态逐行更新在同一 sup 范数事件上逐分量不退化 —— PASS

在同一事件 `E = {‖Q̂ − Q^π‖∞ ≤ E_Q}` 上，对**任意**行更新 `Δπ_s`（即使该行由当步认证数据选出）：

```text
A_s = Σ_a Δπ_s(a)·Q^π(s,a) ≥ Σ_a Δπ_s(a)·Q̂(s,a) − E_Q·‖Δπ_s‖₁ = LB_s
```

算法只采用 `LB_s > 0` 的行，**其余行原样不动**（`Δπ_s = 0 ⟹ A_s = 0`）；且所有候选行均以**旧 `π`**构造（相对 softmax `π·exp(η·Q̂)` 行归一化），**不**用新策略的 `Q` 替换旧策略的 `Q`。`(I − γP^{π'})^{-1} = Σ_t γ^t P^{π' t}` 各项非负，故

```text
v^{π'} − v^π = (I − γP^{π'})^{-1} A ≥ 0   逐分量
```

行选择与 `η` 选择都在**同一个** sup 范数事件内，不引入新的浓度步，也不消耗额外风险。结论是**条件性**（条件于 `E`）的逐分量不退化。
