# 对自己封存结果的对抗性检验（FP-COMPOSE-001 / Claude）

- 程序：`adversarial_checks.py`；输出 `results/FP-COMPOSE-001/claude/verification/adversarial_checks.json`
  （`adversarial_checks.log`）；耗时 31.5 s；对象是**我自己封存的那一份** `formal/task_results.json`。
- 定位：**这不是独立验证，也不提高证据等级。** 同一作者、同一封存包、同一批基线依赖。
  它唯一的价值是**方向相反**——不是再确认一遍，而是**构造能证伪它的检验**。
- 结论：**四项检验全部未发现违规。** 但下面第 5 节说明为什么"未发现"远不等于"已证明"，
  以及为什么其中一项结果**反而不该被读成好消息**。

---

## 1. 为什么需要这四项

`H1` 作为任务单写下的验收项，是**聚合**检查：它问 `E_Q = max_x ε_x/(1−γ)` 是否压住**对偶取 sup** 的实测误差。
而 `L12` 的证明断言的是**严格更强**的东西——**每一对** `x` 都满足

```text
|ρ_x| ≤ |mean_x| + radius_x
```

**聚合通过完全可以与逐对大面积违规并存**，只要违规的那些对不是取到 `max` 的那一对。
这是一个真实的缺口，不是形式主义：`max` 会把 `d` 个对里最宽松的那个推到前面，
而证明的 `union` 恰恰是**为了**允许个别对失效而付的代价。于是前三项检验分别打三个不同的地方：

| 检验 | 打哪里 | 什么样的结果算**证伪** |
|---|---|---|
| 1 逐对浓度 | 证明**实际断言**的逐对界 | 出现 `\|ρ_x\| > \|mean_x\|+r_x` 的对 |
| 2 `y_range` 合法性 | MP 半径所需的**真实值域上界** | 存在某步 `y_range < 2·sup\|Y\|` |
| 3 生产者不读认证批 | T4/T5 的可测性主张 | 用**换过批**的环境重算 `Q̂` 后**不再逐位相同** |
| 4 逐行真实改进 | 机制主张："按状态规则改的每一行都真的改进" | 某个被改的行其真实 `A_s ≤ 0` |

## 2. 检验 1：逐对浓度（27,648 个对-步）

对**全部 1536 个生产者步骤 × 每步 `d` 个对**，用封存的 `(π_before, Q̂)` 从存储的 MDP **精确**算出
`ρ_x = (T^π Q̂)(x) − Q̂(x)`（不抽样），与封存的 `|mean_x| + radius_x` 比较。

| 量 | 值 |
|---|---|
| 核对的对-步数 | **27,648** |
| **单侧违规** | **0** |
| 最小松弛 `min(bound − \|ρ_x\|)` | **`+0.01146`** |
| 双侧区间 `[mean−r, mean+r]` 覆盖率 | `1.0000`（27,648/27,648） |

逐对界在**每一个对上**成立，而不仅仅在聚合意义上成立。双侧覆盖率也是 1，说明单侧结果**不是**"区间中心偏了"的假象。

## 3. 检验 2：`y_range` 是不是合法的值域上界（精确枚举，不抽样）

MP 经验 Bernstein 的半径需要 `Y` 的**真实值域**上界。因为 `Y` 是**后继状态的确定性函数**，
`sup|Y|` 可以从存储的 MDP **精确枚举**，所以这一项可以**确定性地**核对而非统计性地核对。

| 量 | 值 |
|---|---|
| 核对步数 | 1536 |
| 违规（`y_range < 2·sup\|Y\|`） | **0** |
| 最小比值 `y_range / (2·sup\|Y\|)` | **`1.2053`** |
| 中位比值 | `2.6968` |

界**合法**；最紧的一步仍有 20% 余量，典型情况下宽 2.7 倍。

## 4. 检验 3：`Q̂` 真的只是 `(π_before, train)` 的函数

这是 T4/T5 可测性主张的**可证伪形式**。若生产者在步间携带任何隐藏状态——被改动的网络、缓存过的批、累加器——
那么在第 `k>1` 步**只用封存的 `π_before` 与 `train`** 重算，就**不可能**逐位复现封存的 `Q̂`。
为了让检验有咬合力，我在每次重算**之前先故意消费一个无关的认证批**去"污染"隐藏状态。

| 量 | 值 |
|---|---|
| 探针数 | **32**（2 个环境 × 2 路线 × 2 生产者 × 4 步） |
| `numpy` 生产者最大差 | **`0.0`**（逐位） |
| `network` 生产者最大差 | **`0.0`**（逐位） |
| 覆盖的步 | `1, 2, 3, 4`（含 `k>1`） |

没有隐藏状态，没有跨步或跨批的耦合。**`Q̂_k` 是 `(π_before, train)` 的纯函数**——这正是
"`Q̂_k` 为 `H_{k−1}` 可测、且未读 `B_k`"这一条在实测层面的对应物。

## 5. 检验 4：每一行被改的状态，真实改进是否为正（6,642 行）

不退化在任务单里是按**状态聚合**核对的（`v^{π'} − v^π ≥ 0`）。机制主张是**逐行**的：
规则实际动过的每一行都应当满足真实 `A_s > 0`。若 `E_Q` 偏小，完全可能出现某行 `LB_s > 0` 而真实 `A_s < 0`。

| 量 | 值 |
|---|---|
| 被改动的状态-行数 | **6,642** |
| 真实 `A_s ≤ 0` 的行数 | **0** |

（`6,642` 与 `first_result.md` §4.8 的 7,680 行中"未更新 1,038 行"一致：`7,680 − 1,038 = 6,642`。）

## 6. **为什么"0 违规"在这里反而不该被读成好消息**

检验 1 的额度是可以算出来的。每个"格-步"上，对 `d` 个对做 union 给出
`d·δ_dir = δ_step = 0.0125`，于是**允许出现的违规对-步数的期望上界**是

```text
(cell-step 数) × δ_step = 1536 × 0.0125 = 19.2
```

| 量 | 值 |
|---|---|
| 冻结风险预算**允许**的违规数（期望上界） | **19.2** |
| **实测** | **0** |

所以观察到 0，意味着这个界在本协议下**相当松**（松约一个数量级），**不意味着**界是紧的、更不意味着命题被验证。
反过来讲更重要：**假如真的出现了十几处违规，那也完全在界的许可之内，不该被当成警报。**

这就是任务单那句"**0 覆盖违规不是有效性证据**"的**定量形式**——
本项目此前已多次证明不成立的臂也能零违规；这里更进一步：**连"允许有多少违规"都是可算的，而实测远低于额度。**
有效性仍然只来自 T1–T5 门禁 + `L12` 的正确单侧证明 + 条件性不退化证明，**不来自任何计数**。

## 7. 这四项**没有**覆盖什么（如实列出）

1. **没有做独立验证。** 同一作者、同一封存包、同一批共享依赖。**证据等级不变。**
2. **检验 1 用的是单次实现的随机性。** 逐对界是**概率**陈述（每对失败概率 ≤ `δ_dir`），
   这里在**一个已实现的批**上评估它。27,648 个对-步是比 `H1` 精细得多的检验，但它仍是
   **该随机性的一次实现**，不是对概率陈述的证明；换种子/换链数下的表现**未测**。
3. **未检验"给定容量 `n` 时首访集合内的独立性"**——那来自各链独立生成的结构事实
   （见 `shared_generator_review.md` §3 第 6 条）。
4. **未检验 `K>4`。** `y_range` 随步增大（`‖V̂‖∞` 增长），故半径随步增长；
   本次 `K=4` 下无边界问题，但**更长的 horizon 下界会不会松到无法发出，未测**。
   这是一个**具体、可测**的后续问题，不是已知缺陷。
5. **未检验一般环境。** 只有 F1/F2 两族、冻住的那一个协议。

## 8. 判定

- 四项对抗性检验**全部未发现违规**，其中检验 1 与 2 是针对**证明实际断言的形式**（逐对界、值域上界）
  而非任务单的聚合形式，属于**比 `H1` 更强的检验**。
- **这不提高 FP-COMPOSE-001 的证据等级**，也**不替代**独立验证；唯一没能补上的仍是"无第二作者"。
- **它改变的是我对残留风险的判断**：主要风险不再是"某个算术或实现错误没被发现"（逐对、逐行、
  逐位三处都打过），而是"**共同的概念性错误**"——那只能用不共享我思路的读者来打。
