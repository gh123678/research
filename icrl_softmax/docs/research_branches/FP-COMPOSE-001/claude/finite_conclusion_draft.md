## 1. 结论（一句话）

**在 FP-COMPOSE-001 所冻结的有限环境、输入、浮点实现与单轨迹风险协议下，"固定权重注意力网络产生 `Q̂` → 外部 `L12` 对该网络自身输出给出误差证书 → 外部按状态规则作更新"这条实际执行链，逐项前提成立、四步连续运行、判决在两生产者间完全一致，且每一步都未退化。**

**这是一次有限协议下的组合验证，不是关于该组合的定理，也不是三项的联合概率保证。**

## 3. 有限主张（可复核，请连同条件一起引用）

**条件**：F1 `S=6,A=4,γ=0.70,gap_bonus=0.5,R*=1.5,mixing=(0.08,0.5),task 200..223`；
F2 `S=4,A=3,γ=0.70,gap_bonus=1.0,R*=2.0,mixing=(0.2,0.7),task 300..323`；
路线 `expected_exact`/`expected_finite`；生产者 numpy float64 与 `model.py` 字面注意力网络 float32；
`K=4`；每步独立认证批 16,384 链 × 64 项；首访保留、每对 `min_visits=2000`；
`delta_total=0.05`、`delta_step=0.0125`、`delta_dir=delta_step/(S·A)`；`η` 网格 `(1,.5,.2,.1,.05,.02,.01)`；
按状态规则逐行取第一个 `LB_s>0` 的 `η`，未通过行原样不动；`L12` 标量 `E_Q = max_x(|mean_x|+radius_x)/(1−γ)`，**无核、无传播**。

**主张**：在该条件下，

1. **每一步的 `E_Q` 都不小于该步该格自身实测的 `‖Q̂−Q^π_old‖∞`**：1536 步实测 0 违规，最小安全余量 `+0.114711`（`E_Q` 均值 `0.2107`）。用的是不依赖 `policy_quantities` 的独立线性求解。
2. **每一个发出步骤都逐分量不退化**：1536 步实测，最小逐状态价值增量 `+0.002863`。
3. **组合非空且多步**：4 个 (族,路线) 分组中，网络生产者各 `48/48` 条轨迹有 ≥2 步**连续**发出（最大连续 4）。
4. **两生产者的判决完全对应**：**192/192** 条路线记录的发出/弃权序列与逐行 `η`（含"不更新"标记）完全相同——**并且这不是因为数值相同**：13,824 个 `(s,a)` 的 `Q̂` 中**按位相等的有 0 个**（自身路径最大差 `1.7175e-05`）。
5. **成本已如实记录**：配对真实抽取 384 批 / `402,653,184` 项；若每格单独运行 `1,610,612,736` 项；网络前向 768 次；总墙钟 `1518.2 s`（采样 `80.4`、生产者 `1148.0`、证书与判决 `22.8`、审计 `0.2`、同策略额外重算 `175.4`，最后一项单列）。

**证据位置**：`results/FP-COMPOSE-001/claude/formal/{task_results.json,analysis.json,input_manifest.json}`；
`docs/research_branches/FP-COMPOSE-001/claude/first_result.md`（封存提交 `629d4fa`）。

## 4. 明确不主张（与 §3 同等重要）

- **不是三项的联合验证。** 这是**一次有限协议下的组合运行**：真实概率内容仍是**单条生产者-路线轨迹级**（`δ_total=0.05`），**不覆盖** 192 条记录或两生产者的联合事件。三项"分别成立"加一次组合运行，**不等于**三项构成已证的系统定理。
- **"0 违规"不是有效性证据。** 本项目已多次证明：不成立的臂也能零违规。有效性来自 T1–T5 门禁、`L12` 的正确**单侧**证明与条件性不退化证明，**不来自计数**。
- **不主张一般等成本优势**；强命题"严格等实际总数据下显著更好"已撤回，逐环境并非普遍占优。
- **不主张后段收益为零或非零**；`K=4` 不支持任何收敛主张，"几何收敛/每步减半/第 10 步归零"均不成立，"后段只是空转"过强。
- **不主张任何跨精度、跨种子、跨机器的稳定性**；"误差不随维度增长"仍只是"这两族上未观察到"（该规律已判 FAIL）。
- **不主张网络自我认证**：网络只产生 `Q̂`；证书由**外部** `L12` 给出。
- **不主张 `L12M`/`L12S`/`L123` 或任何传播构造有效或无效**：本组合**未使用**任何传播构造，对它们不发一言；`L12S` 的保证全数撤回，传播路径**未修复**（暂缓是优先级决定，不是否定该方向）。
- **不主张浮点形式化保证**：概率论证支持理想实数协议，`Q̂` 的已输出浮点值作为确定输入处理。
- **不主张本轮是泛化发现**：复用已测环境，是**确认性**组合验证。

### 7.2 一个具体、可测的后续问题（本次已量化，仍未测）

`y_range = 2(R* + γ‖V̂‖∞ + ‖Q̂‖∞)` 随步增大（`‖V̂‖∞` 增长），故 `L12` 半径随步增长。
`K=4` 下没有停点（最紧一格余量 `h/E_Q = 1.088`），但**余量以约 −9%/步收窄**。

[`headroom_analysis.md`](headroom_analysis.md) 把它量化了，并给出我认为最重要的结论：
**收窄的主要来源不是问题变难，而是冻结的 `y_range` 公式相对 `Y` 的真实值域松了 2.5–3.1 倍（且随步增长到 3.4–4.6 倍），
而本项目自己的单侧证明文档早已推导出更紧的 `2R* + γ·span(V̂)`。** `E_Q` 四步只涨 ×1.06–1.17。

**据此可预登记一条 `K>4` 的预测**（供未来任务检验，我现在不跑）：按 −9%/步外推，
f1 中位约在第 12 步、f2 约在第 16 步触到 `h/E_Q = 1`，而最紧那一格约再 1 步。
**这是从 4 个点做的对数线性外推，不是测量。** 它问的是"**这条接缝在什么条件下失效**"，
比"再换一个环境"信息量大。
