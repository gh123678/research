# FP-EXPL-001：固定探索批次的迭代结论

任务状态：VERIFIED（2026-09-11；正式状态以 ACTIVE_WORKSPACE.md 为准）。

本任务沿用自己的状态动作对组内平均公式：先用固定行为策略采集一条
64 步连续轨迹，冻结数据，再评估固定目标策略。有限 softmax 网络每轮
更新 Q，目标策略、行为策略和数据均不随迭代改变。

## 目前得到的证据

四个状态动作对的访问次数为 `[19,16,12,17]`，本批覆盖检查通过。
这不能解释为“行为策略有全支持，所以任意有限样本一定全覆盖”。
代码没有补样、重选种子或选择有利的批次。

独立重建的组内平均公式与保存的网络投影和完整轨迹一致。
同一批数据上，精确算子和有限 softmax 算子都收缩；本批两者的
无穷范数收缩系数为 `0.85`。GPT 验收报告用有理数不等式补充了
有限算子非负性与行和的证明。

## 三种最终误差

令 q_hat 为精确经验算子的固定点，q_f 为有限 softmax 算子的固定点，
q_pi 为真实环境的固定策略价值。第 64 轮满足有符号向量等式：

    Q_64 - q_pi = (Q_64 - q_f) + (q_f - q_hat) + (q_hat - q_pi)

| 分量 | 含义 | 本批无穷范数，约 |
|---|---|---:|
| 迭代误差 | 有限网络离自己的固定点还有多远 | 0.00004894 |
| 有限 softmax 误差 | 有限网络固定点与精确经验固定点的差 | 0.00179092 |
| 数据误差 | 这批经验数据与真实环境产生的固定点差 | 0.03806150 |

第 64 轮总误差约为 `0.03858201`。向量项可以抵消，因此上表三个范数
相加只给上界。这里的数据误差是单批实现的偏差，不是期望意义下的
统计偏差估计；只用一个种子不能估计其分布。

当前误差主要来自数据：把同一批数据继续迭代下去，迭代项会消失，
数据项仍在。三种最终误差也不同于网络内部的“当前 Q 读取、后继动作
平均、写回聚合”三个阶段误差；后者用于解释同输入的一步算子差。

## 结论边界与下一步方向

这一步支持“固定探索采样后，组内平均 Q 迭代可由该有限 softmax 构造
实现，并能区分迭代、构造和数据误差”。它没有验证策略改进、在线控制
或一般样本复杂度，也没有采用参考论文的整批访问频率加权公式。

下一步最有价值的问题是：固定策略下，真实轨迹的覆盖条件和采样误差
怎样进入可证明的界。尤其要区分本批可检查的覆盖事件、一般有限样本
覆盖概率，以及依赖真实 q_pi 的审计上界。该方向需要新的正式任务单；
本任务只收尾已冻结的构造与验证。
