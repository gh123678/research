## 送审项 2：免费证书杠杆 `L1` / `L12`

### 必答专项检查：`L1`、`L12` 均**通过此专项检查**（但项 2 整体不通过，原因在别处）

**没有**把"由数据算出的函数"送进只能用于固定函数的浓度不等式。

- `L1`：`E_eff = R* + γ‖V̂‖∞ + ‖Q̂‖∞`（`fixed_policy_tight_certificate.py:84-101`）是 `(q_hat, policy)` 的**确定性**函数，且 `|Y_x| ≤ E_eff` 是**逐点确定**的界，连独立性都不是它成立的前提；`q_hat ⊥ B_k` 结构上成立（`evaluate_fp_rerun_001.py:99-123`；`evaluate_fp_bound_001.py:96-114`），条件于 `q_hat` 残差 iid。定理 2 的 `B_k ⊥ H_{k-1}` **确实由"每步新批次"保证**——批的种子只依赖 `(…, step)`（`fp_certfix_first_n.step_seed_parts`）。
- `L12`：与 `L1` 只差风险分配，无迭代、无递推、无"用同一样本估计自身"。缺陷类不存在。

### 但是：`L12` 的**风险账务不成立** → 本项 **FAIL**

**关键事实**：`fixed_policy_tight_certificate.py:506`
```python
delta_dir = float(delta_step) / (d if use_full_budget else 2.0 * d)
```
配上 `:515` `log_term = math.log(2.0 / delta_dir)`。`use_full_budget` 仅在 `("L12", "L123")` 为真。

**当前论证**（`FP-BOUND-002…split-repair.md:47-60` §3）说：实现里 `delta_dir = δ_pair/2`，`log(2/delta_dir) = log(4/δ_pair)` 恰是严格双侧所需，故 "MP 各臂（`frozen`/`L1`/`L12`/`L123`）的数值不受影响，只改文字"。**这句话只对 `delta_dir = δ_step/(2d)` 的臂成立**，而 `L12`/`L123` 的 `delta_dir = δ_step/d` 是它的 **2 倍**，所以该论证对它们不适用。

**独立重证（替代论证）**：MP Thm 4 单侧、风险 `δ_dir`、对数项 `log(2/δ_dir)`；要得 `|ρ_x|` 的双侧界须对 `Z` 与 `−Z` 各用一次，每对风险 `2·δ_dir`。
- `frozen`/`L1`：`2·(δ_step/2d)·d = δ_step` ✅ 正好花满预算。
- `L12`：`2·(δ_step/d)·d = 2·δ_step` ❌ **超支一倍**。

代码自己的约定也印证这一点：`L12S` 分支（`:288-293`）明写 "two-sided at total per-pair risk `delta_eps/d` == one-sided at `delta_eps/(2d)`"，并令 `delta_dir = delta_eps/(2d)`。同一约定下 `L12` 应为 `δ_step/(2d)`，即**与 `L1` 完全相同**。

**推论（可直接检查）**：在名义 `δ_step` 下 `L12` 的半径本就该等于 `L1` 的半径；`L12` 相比 `L1` 的全部差值（`−13.5%` vs `−11.0%`，对数项 `6.17` vs `6.87`，差正好 `log 2 = 0.693`）就是这次**风险欠付**买来的。因此：
- 送审项 2 的 `L12 −13.5%`、"两者无模型、零概率代价"**在 `δ_step` 下无授权**；
- `FP-RERUN-001` 的 `L12` 迭代结论（`frozen 36 → L12 66`、`1.734 → 2.377`，`first_result.md:43,51`）用的就是这一格，随之一并失去授权；
- **`L1` 的 `−11.0%` 不受影响**（账务正确），它才是唯一存活的免费杠杆。

**验证套件抓不到它，而且复写了同一错误前提**：`verify_fp_bound_001.py:22-23` 与 `:148-153` 把 "`d·δ_each = δ_step`（full-budget）" 写死为检查项。C6 报 PASS 只是把错前提又确认了一遍——正是简报警告的失效模式（检查器共享协议信念）。受影响还含 `L123`（同为 full-budget），但它是 oracle 参照臂。

**文件/行**：`fixed_policy_tight_certificate.py:506,515`；`verify_fp_bound_001.py:22-23,142-153`；`docs/research_branches/FP-BOUND-001/claude/first_result.md` §2（L2 陈述）与 §6 C6；`docs/derivations/FP-BOUND-002-l12m-withdrawal-and-split-repair.md:47-60`。

### 裁决：**FAIL**（`L12` 部分；`L1` 部分 PASS）

区分：当前论证（"数值不变"）与替代论证（2× 超支）如上，二者不可同真。
可供主人裁决的选项：① 把 `L12` 各项数字改注为"在 `2δ_step` 下有效"；② 按 `delta_dir = δ_step/(2d)` 重算，此时 `L12` 塌缩为 `L1`，`L12` 作为独立杠杆应撤回；③ 维持现状但把 `L12` 的保证声明一并撤回。
未验证项：`L12` 重算后的具体数值（本会话不能执行）；`L123` 受影响幅度。
