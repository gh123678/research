## 附录 A：frozen 常数 `Y_RANGE=20` 在 F2 上是否可用

**先确认代码路径（GPT 前提的前半句成立）：** F1/F2 的 `frozen` 格走的是 `evaluate_fp_xrule_001.py:65,141-150` → `tc.certificate(..., lever="frozen", reward_bound=fam["reward_bound"], ...)`。而 `fixed_policy_tight_certificate.py:496-500` 中 `use_eff = lever != "frozen"`，故 `frozen` 恒取模块常数 `Y_RANGE = 2*ENVELOPE = 20`（`:66`），**不随 `reward_bound` 参数化**；`_guards(..., reward_bound=2.0)`（`:426`）则用族级 `R*` 作 `|Q̂| ≤ R*/(1−γ) = 6.667` 的守卫。（另一文件 `evaluate_fp_xfam_001.py:309` 走 `mc.mp_certificate_firstvisit`，其 `y_range = 2(R*+γB+B)` **会**随族重算为 26.667；但该路径不产出本三项的 F1/F2 封存结果。）

**核验 GPT 的不等式链：**
- 逐固定对 x，`Y_x = R + γV̂(s') − Q̂(x)`，其中 `−Q̂(x)` 是常数 ⇒ **不影响值域长度**（"fixed-pair shift"成立）。
- `span(Y_x) ≤ span(R) + γ·span(V̂) ≤ 2R* + 2γ‖V̂‖∞`。
- 守卫 `|Q̂| ≤ R*/(1−γ)` ⇒ `‖V̂‖∞ = max_s|Σ_a π Q̂| ≤ max|Q̂| ≤ R*/(1−γ)`。
- ⇒ `span(Y_x) ≤ 2R* + 2γR*/(1−γ) = 2R*/(1−γ)`。F2：`4/0.3 = 13.333`；F1：`3/0.3 = 10`。（该式与 `2·ENVELOPE` 代数恒等，故此前把"对称包络"当尺子才会得 26.667。）
- `20 ≥ 13.333`，故 `Y_RANGE=20` 在 F2 是**有效上界**（保守，非最紧）。**PASS。**
- 精确可用条件（可查、可推广判据）：**`2R*/(1−γ) ≤ 20 ⟺ R* ≤ 10(1−γ)`**；γ=0.7 时即 `R* ≤ 3.0`。F1（1.5）、F2（2.0）满足。

**两点必须同时记录的收窄：**
1. GPT 的表述"frozen 的 `Y_RANGE` 固定 20 在 F2 **未随 R*=2 参数化**"**属实且是关键**；但要说清这是 **tight 模块常数**的性质，同族另一个（未用于本三项的）路径会把它重算成 26.667。
2. **这不是"必然无效"，但也不是普遍可用**：`R* > 3.0`（γ=0.7）的新族上，`frozen` 杠杆会**静默失效**——守卫仍按族级 `R*` 放行，常数却成了不合法值域。当前两族安全；κ向任意奖励/折扣的泛化**不在**本复核通过范围，须另设参数化或加断言。
