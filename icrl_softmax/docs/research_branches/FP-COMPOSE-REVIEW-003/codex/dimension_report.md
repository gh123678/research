## 2. 仍不成立的推论

1. **维度与族混杂**：两点同时改变 S、A、mixing、奖励、任务和行为占用率。它们不是只改变 d 的受控数据，拟合斜率不是独立识别的维度效应。
2. **合成锚点不是中位轨迹**：作者取 F1 的 E_Q 中位，却使用两族及全部发出步骤合并的 h/方差/包络中位。实算 F1 h 中位 0.5191485142779484、F2 0.733072935995357；F1 实测 E_Q/h 中位 0.5428867525954408，而合成锚点比值仅 0.44179669840929486。一般 median(E)/median(h) 不等于 median(E/h)，混合不同族后更不能称为 F1 的中位门限。
3. **省略效应不具有已证的共同方向**：变大状态空间不必增大奖励尺度、价值范数或残差方差，也不必减小 h。复制同构状态/动作标签可保持价值与条件残差结构；也可改变动作差距使 h 增大。没有嵌套、同分布等前提时，“更多对取最大”也不能独自建立新环境的 E_Q 单调性。因此 d=64–96 不是已证明上界，链数不是已证明下界。
4. **“加链数是在不承重项上花钱”不由先关顺序推出**：本条针对作者 dimension_scaling.md §7 最后一段的资源解释，不反对其模型内的先关顺序。模型自己解“保持门限”的链数即依赖增加计数降低半径，所以增加链数仍能缓解门限约束。正确表述是：假设模型中门限比硬性 min_visits 阈值更早触发，按支持阈值配置的链数未必足够；不能把“满足支持阈值仍不足”解释为“增加链数不解决门限”。
5. **网格首个失败点不是连续临界点**：96/64 是扫过的离散网格首个关门点，不是精确求得的临界维度。中位层面的关门也不意味着所有环境都不能更新。
6. **两小时运行预算未被估计**：链数倍数只计采样，实际网络构造有与 d 相关的 attention 张量，完整运行还包含训练批生成、160 层前向、两种路线/全部步数。未经扩维运行或成本模型，不能保证在既有两小时预算内完成。
7. **d<=L 时每对覆盖随 d 改善的开场机制错误**：能在长度 L 内访问所有对只说明组合上可能，不保证覆盖提升。作者两点实测也呈下降；在均匀独立对模型中覆盖率 1-(1-1/d)^L 随 d 下降。

因此“模型算出门限先关”的描述可以保留，但要明确所有冻结锚点与假设；“真实天花板”“所有省略效应同向”“代价下界”“已经关掉一种实验方向”应撤回。本次未新增任意维度的实验。
