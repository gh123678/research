## T1 历史条件、可测性与认证批独立性 —— PASS

对每格（record, arm, producer）每步 `k = 1..12` 列 `H_(k-1) = σ(MDP, train, B_1, …, B_(k-1))`：

1. **`Q̂_k` 与 `π_(k-1)` 是 `H_(k-1)` 可测的。** 两者只由 `train`、初始策略与前 `k−1` 步判决决定；判决只由各自步的
   `Q̂`、`E_Q`、`LB` 决定。归纳步无缺口。
2. **未读本步批。** 认证批由 `seed_parts = [SEED, SALT, round(100·mixing), task_index, step]` 经
   `default_rng(seed_parts)` 独立生成（§10.5），与环境/训练批的 rng 流**无任何共享状态**（那一路在 §10.4 结束）。
   实现中 `raw` 的抽取写在 `Q̂` 计算之前还是之后不影响可测性；依据是**计算依赖关系**：`Q̂` 的输入只有 `(π, train)`。
3. **`Y_x` 是固定函数。** `Y_x = R[s,a,s′] + γ·Σ_b π[s′,b]·Q̂[s′,b] − Q̂[s,a]`；`(π, Q̂)` 给定 `H_(k-1)` 后固定，
   故 `Y_x` 的分布 `P_x` 固定（行为策略只影响访问次数）。
4. **首访样本在给定容量下 iid（引理 A′，内联陈述）**：每条链对每对只保留**首访**残差；链的首访指示 `G_c`
   由首访前轨迹决定，取值在首访处新鲜抽取，故 `Y_c ⊥ 1{G_c}`；条件于 `N_x = n` 样本为 `P_x^{⊗n}`。
   **只有 `first_visit` 保留协议被授权**；固定计数（"每对前 n 个"）的停时论证已证伪（`FP-L12S-REVIEW-001`），不得使用。
5. **风险积分与 union 的顺序**：先对每对的随机容量 `n` 取全期望（`N_x` 与取值独立，故无 union 代价），
   再对 `d = 12` 个对做 union。
6. **风险是单条轨迹级**（`delta_total = 0.05` per (actor, record, arm, producer) 轨迹）；
   **不声称** 48 记录、两生产者或两 actor 的联合保证。

## T2 frozen 包络证书的目标——**幅值**界，不是中心区间 —— PASS

证书输出标量 `eps_x = |mean_x| + radius_x`，`E_Q = max_x eps_x/(1−γ)`。所需命题是
`|ρ_x| ≤ |mean_x| + radius_x`，其中 `ρ_x` 是真实、历史可测的 Bellman 残差均值。

按 `ρ_x` 的符号分情形（`radius` 对 `Y → −Y` 不变）：

- `ρ_x ≥ 0`：只用 MP 的**上侧**方向 `ρ_x − mean_x ≤ r_x`，得 `|ρ_x| ≤ mean_x + r_x ≤ |mean_x| + r_x`；
- `ρ_x < 0`：只对 `−Y` 用 MP，得 `|ρ_x| ≤ −mean_x + r_x ≤ |mean_x| + r_x`；
- `ρ_x = 0`：平凡成立。

故每个**固定分布**只需 MP 的**一个方向**，`Pr{|ρ_x| > |mean_x| + r_x | H, n} ≤ delta_dir`；
`δ_dir = δ_step/(2d)` 对幅值目标至多花 `δ_step/2`（保守花费），跨步 `≤ δ_total`。

**半径的经验 Bernstein 形式**（逐字冻结）：`sqrt(2·var_x·lt/N_x) + (7/3)·y_range·lt/max(N_x−1, 1)`，
`lt = log(2/δ_dir)`，`ddof=1`，`MP_CONSTANT = 7/3`。

**包络前提**：`range(Y_x) ≤ 2R* + γ·span(V̂) ≤ 2R*/(1−γ)`；本族 `R* = 1.5` 给出 `2·1.5/0.3 = 10 < y_range = 20`。
`y_range` 是**冻结常数**（`2·(R* + γ·5 + 5) = 20`），**不含任何浓度步骤**。

**明确不复用**"MP 双侧"的旧错误解释，不把幅值界写成中心区间 `|mean − ρ| ≤ r`；不额外声称联合保证。

## T3 按状态/合取更新在同一 sup 范数事件上逐分量不退化 —— PASS

在同一事件 `E = {‖Q̂ − Q^π‖∞ ≤ E_Q}` 上，对**任意**行更新 `Δπ_s`（即使该行由当步认证数据选出）：

```text
A_s = Σ_a Δπ_s(a)·Q^π(s,a) ≥ Σ_a Δπ_s(a)·Q̂(s,a) − E_Q·‖Δπ_s‖₁ = LB_s
```

- 合取臂：整格采用 `min_s LB_s > 0` 的候选，故所有行同时满足；
- 按状态臂：只采用 `LB_s > 0` 的行，其余行原样不动（`Δπ_s = 0 ⟹ A_s = 0`）；
- 所有候选均以**旧 π** 构造（相对 softmax `π·exp(η·Q̂)` 行归一化），**不**用新策略的 `Q` 替换旧策略的 `Q`。

`(I − γP^{π'})^{-1} = Σ_t γ^t P^{π't}` 各项非负，故

```text
v^{π'} − v^π = (I − γP^{π'})^{-1} A ≥ 0   逐分量
```

行选择与 `η` 选择都在**同一个** sup 范数事件内，不引入新的浓度步，也不消耗额外风险。
结论是**条件性**（条件于 `E`）的逐分量不退化。实现审计用的容差 `min Δv ≥ −1e-12` 沿自 `FP-EARLYSTOP-001` v2。

## T4 生产者的实现边界与证书的输入边界 —— PASS

- 生产者（数组两条路线 + 网络两个变体）只读 `(π, train)`，**不读认证批**；网络权重由结构给定且固定，
  不训练、无梯度步；两个网络类**无 trainable parameters**（`state_dict()` 为空，已由 `FP-MODEL-REVIEW-001` 实测）。
- 证书只读 `(Q̂, 认证批)`；frozen 分支**不使用** MDP 核/真值。
- 判决只需 `(π, Q̂, E_Q)`。
- **核与精确值只在隔离审计通道**使用（实测 `‖Q̂−Q^π‖∞`、逐状态价值、价值增量、`v*`），审计结果**不参与**任何决策。
- 网络/数组都返回原始输出；不存在任何提高彼此一致性的修正。
