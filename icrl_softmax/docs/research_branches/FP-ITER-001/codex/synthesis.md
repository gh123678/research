## 已经得到的证据

1. **显式注意力矩阵确实能执行规定的更新。** 已写出读取、残差、写回的
   完整构造，与独立公式逐步比较。6,332 项本地检查全部通过。
2. **在完整覆盖的例子中，有限注意力可以稳定迭代。** 锐度为 8 时，收缩
   因子约为 0.851，小于 1；最终点与精确经验评价相差约 0.00162，低于
   已验证的误差上界 0.00392。
3. **覆盖缺口不能靠 softmax 自动补上。** 去掉一个动作的全部数据后，
   精确更新保留该动作的原值；有限 softmax 却把其他动作的残差写进去。
   从 0 开始，该动作在第 64 步变成约 1.493。这种变化不能解释为学到了
   缺失动作的价值。
4. **迭代能停下来，也可能停错地方。** 锐度为 0 时，不同初始 Q 会走向
   不同的固定点。仅看数值稳定，不足以判定评价正确。

还要看它收敛到哪里、与正确评价差多少，以及这些差异从哪里来。**

## 你现在需要掌握的三个区别

- **迭代还没结束的误差**：同一个更新继续做下去，这部分通常会缩小。
- **注意力近似误差**：即使收敛了，有限 softmax 的固定点也可能偏离精确更新。
- **数据误差**：即使把这批数据算得完全准确，也可能偏离真实环境的策略价值。

本次完整覆盖的例子验证了前两部分，但第三部分恰好为零。下一份任务
应保留固定策略和小规模设置，预先冻结一个第三部分不为零的例子，检验
三部分的分解以及迭代中的误差界。不能通过不断调整输入来挑选好看的结果。
缺失动作的写入问题作为当前构造边界保留，暂不把它解释成策略改进。

你现在的工作是读懂这三个区别，并能解释“多迭代几次能消除哪一种误差”。
