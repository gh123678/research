## 2. 引理 A'：我独立重证为**真**

作者给出的证明骨架正确，但其中第 (2) 条的理由写得太简（"`N` 是访问指示的函数，而每个取值与相应指示独立"——逐对独立本身不足以推出联合独立）。我把完整论证补上，并确认结论无误。

**记号。** `C` 条独立链，起点 iid `~μ^β`，按 `β` 演化，长度 `L`。对链 `c`：`τ_c` = 首次访问 `x` 的时刻（`L` 步内未访问则 `τ_c = ∞`），`G_c = {τ_c < ∞}`，`Y_c` = 首访处的残差。设 `H = σ(F_{τ_c} : c = 1..C)`（`τ_c = ∞` 时取 `F_∞ = F_L`）。

**证明。**
1. `G_c ∈ F_{τ_c}`：`{τ_c ≤ L}` 由前 `L` 步轨迹决定，故 `∈ F_L ⊆ F_{τ_c}`（对停时 `F_τ` 的定义逐条核对：取 `A = {τ_c ≤ t}`，`A ∩ {τ_c ≤ t} = {τ_c ≤ t} ∈ F_t` ✓）。因此 `H` 包含全部 `G_c`，特别地 `N = Σ_c 1{G_c}` 是 `H` 可测的。
2. 强马尔可夫 + 新鲜抽取：`P(Y_c ∈ B | F_{τ_c}) = P_x(B)` a.s. 于 `G_c`。首访处的后继从 `P(·|x)` 抽取，与首访前的历史无关，也与访问时刻无关（链是时齐的）。
3. 链间独立 ⟹ 给定 `H`，`{Y_c : c ∈ S}`（`S = {c : G_c = 1}`）相互独立且各自服从 `P_x`。
4. 于是对任意有界 `f`、任意 `n`：`E[f(Y_{c_1},…,Y_{c_n})·1{N = n}] = P(N = n)·E_{P_x^{⊗n}}[f]`。这正是"在 `{N = n}` 下样本为 `P_x^{⊗n}`"，且对 `N` 积分**不产生 union 代价**——因为条件是"给定 `H`"，而 `N` 是 `H` 可测的，不是对 `N` 的每一个取值做一次 union。

**与旧引理 A 的差别正是致命处。** 旧论证在归纳步把 `{τ_n < ∞}` 当作 `F_{τ_{n-1}}` 可测提出去；但"链是否会再次回到 `x`"取决于 `τ_{n-1}` 处抽到的后继，也就是 `Y_{n−1}` 本身。A' 不再迭代，所以这个缺口不存在。

**实现侧的两个前提我逐条核对过，都成立。**
- 链确实相互独立（`fp_sample_vectorised_batch.vectorised_batch` 每条链独立从 `μ^β` 起步；按块向量化不影响独立性）。
- `first_visit_batch` 取的是**首次**访问（`mask[has].argmax(axis=1)`），且每链每对只留 1 个样本 ✓（`fp_certfix_first_n.py:59-69`）。
- 未访问的链不进入样本，`N_x` 因此是"访问过该对的链数"，与取值独立 ✓。

**两个非阻断的改进建议（不影响结论）：**
- §1 第 (2) 条建议直接写"给定 `H = σ(F_{τ_c})`"，一步到位；否则读者需要自己补出联合独立那一步。
- `Y_c` 在 `{G_c = 0}` 上没有定义，严格写法应说明"只在 `G_c = 1` 上使用条件分布"，或在证明里显式条件化到 `H` 上（本审读采用后者）。

## 6. 覆盖实验：没有前提失效的迹象，但覆盖率远高于名义值

`tmp/review2_lemma_A_prime.py`，6 个冻结环境 × 150 次独立重复（chains=3000, L=64）：

- 记录级 `‖Qhat − Q^π‖∞ ≤ E_Q`：**0/900 失效**（名义 ≤ 5%）。
- 逐对级 `|mean_x − ρ_x| ≤ t_x`：**0/10800 失效**（名义 0.83%）。
- `N_x` 与取值的相关：72 个 `corr(N_x, mean_x)` 绝对值最大 0.238；在 150 次重复下相关系数标准误 ≈ 0.082，72 个独立取值的最大 |corr| 期望正是 ≈ 0.24——**与"独立"完全吻合，无漂移证据**。

**但必须如实说明这个实验测的是什么。** 覆盖率远高于名义值，是因为封存数据里 `realized/E_Q` 的中位数只有 0.10–0.19（逐档：`step1_fv_c16k` 中位 0.098、最大 0.157；`step1_fv_c64k` 中位 0.192、最大 0.336；`multi_fv` 中位 0.079）。也就是说 **`E_Q` 平均比真实误差大 5–10 倍，最松处大 37 倍**。所以：
- 本实验是对**前提**（iid / `N ⊥ 取值`）的检验，结论是"没有失效迹象"，有效；
- 它**不是**对界的紧致性的检验，不能用来支持"证书已经够紧"。

这也重新定位了整个修复线的瓶颈：**卡住发出数的不是数据量，而是界的保守度**。`c16k → c64k` 把 `E_Q` 中位数从 0.2150 压到 0.1011（≈2.1×，与 `1/√n` 一致），发出数 22 → 38；但要再往前走，靠加数据的边际收益是 `1/√n`。
