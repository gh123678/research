# FP-BOUND-002/003 勘误与修复：`L12M` 的浓度步不成立，改用切半协议 `L12S`

- 日期：2026-09-13
- 触发：独立审计（用户，2026-09-13）第 1 条与第 2 条
- 影响范围：`FP-BOUND-002`、`FP-BOUND-003`、`FP-ITER-BOUND-001`、`FP-ITER-BOUND-002`、`FP-NET-BOUND-001` 中一切引用 `L12M` 的数字
- 结论：**`L12M` 的保证撤回**（保留代码仅供复现当日封存）；修复后的 `L12S` 是有效的，但收益从 `−39.6%` 降到 **`−31.2%`**

## 1. 缺陷（审计第 1 条，属实）

`L12M` 的构造是

```text
W_0        = max_x ε_x/(1−γ)
W_{k+1}(s) = ε̄(s) + γ Σ_a π(a|s) [ T_x(W_k) + c_k(x) ]
T_x(f)     = (1/n_x) Σ_i f(s′_i),      c_k(x) = ‖W_k‖∞ sqrt(log(1/δ_k)/(2 n_x))
```

其中 `c_k` 是对 `T_x(W_k)` 的 Hoeffding 修正。**这一步不成立**：Hoeffding 要求被平均的函数固定，而 `W_k` 本身是用同一批后继观测递推算出来的（`W_1` 就依赖 `T_x(W_0)`，而 `W_0` 又依赖由同一批样本算出的 `ε`）。数据依赖的函数可以与"估计它均值的那批样本"反向对齐：取 `f_i = 1{s′_i ∈ A}` 而 `A` 由观测到的 `s′_i` 决定，则 `T_x(f) = 1` 而 `E[f]` 可以很小——此时 `T_x(f) ≤ E[f] + c` 的概率远低于名义水平。

后果：`L12M` 的归纳无效，其 `E_Q` **不是一个有效的界**。观测到的 `0` 覆盖违规不构成证据（本项目已多次证明：不成立的臂也能 0 违规）。

## 2. 修复：切半协议 `L12S`

把每对保留的首访样本**按保留顺序**切成 A 半（前 `⌊f·n_x⌋`）与 B 半。条件于 A 半：

- 区间 `|ρ_x| ≤ ε_x` 是**固定**向量（其中不含 B 半任何信息）；
- `E_eff` 是 `(Q̂, π)` 的确定性函数；
- 于是 `V_0 = max_x ε_x/(1−γ)` 固定，且每个
  `V_{k+1}(s) = ε̄(s) + γ Σ_a π(a|s)[ T^B_x(V_k) + c_k(x) ]` 都固定；
- `T^B_x` 与 `c_k(x) = ‖V_k‖∞ sqrt(log(1/δ_k)/(2 n_{B,x}))` 在 **B 半**上计算，而 **B 半与 A 半独立**（条件于 `N_x = n` 后首访样本 iid，确定性切分——与推导 §7 同一论证）。

因此每一步浓度不等式都作用在**固定**函数上，合法；归纳 `|w| ≤ V_k` 成立，最终
`E_Q = max_{s,a} [ ε(s,a) + γ (T^B_x(V_K) + c_K(x)) ]` 是有效界。

**风险**：`δ_eps + δ_prop = δ_step`，两者都可由参数分配；传播部分再对 `K·d` 个 (迭代, 对) 事件与 `d` 个最终事件做 union。

**实现**：`fixed_policy_tight_certificate.split_sample_certificate` / `propagation_split`，lever 名 `L12S`，参数 `split_fraction`（A 半占比，默认 `0.5`）与 `delta_prop_fraction`（默认 `0.5`）。`L12M` 保留原样以便复现当日封存，并在模块中标记为 `WITHDRAWN_LEVERS`。

## 3. 审计第 2 条：Maurer–Pontil 是**单侧**定理

已核对原文（[Maurer & Pontil 2009, Thm 4](https://ar5iv.labs.arxiv.org/html/0907.3740)）：其陈述为

```text
E[Z] − (1/n)Σ Z_i ≤ sqrt(2 V_n(Z) ln(2/δ)/n) + 7 ln(2/δ) / (3(n−1))     概率 ≥ 1−δ
```

**只有上侧**。文档中"Thm 4（双侧，每对每方向 δ_step/(2d)）"的写法是错的。正确的推法是把该单侧界分别用于 `Z` 与 `1−Z`（两者样本方差相同），各花 `δ_pair/2`，得双侧形式，其对数项为 `log(2/(δ_pair/2)) = log(4/δ_pair)`。

**数值不变，这一点要点明**：实现里 `delta_dir = δ_pair/2` 且取 `log(2/delta_dir) = log(4/δ_pair)`，**恰好等于**严格双侧形式所要求的对数项。所以
- 按单侧读法：每事件风险 `delta_dir`，`2d` 个事件，合计 `2d·delta_dir = δ_step`；
- 按双侧读法：每对风险 `2·delta_dir`，`d` 对，合计 `δ_step`；
两种读法给出**同一个** `log` 与**同一个**总风险。因此 `MP` 各臂（`frozen`/`L1`/`L12`/`L123`）的数值不受影响，需要改的只是文档与验收依据的措辞。`L12S` 中同样按此写法实现。

## 4. 实测：修复后的价格与收益（`c64k`，48 条记录，同一批配对比较）

`L12S` 的两个旋钮都不是默认值最优。切半把区间样本量降为 `f·n_x`，而传播的置信项只有 `O(1e-3)`——FP-BOUND-003 已经证明它不需要多少风险预算。网格（`measure_fp_bound_005.py`）：

| 配置 | 均值 `E_Q` | 相对冻结 | 相对 `L12` | 第一步发出 | 覆盖违规 |
|---|---:|---:|---:|---:|---:|
| `frozen` | `0.12044` | — | — | `34` | `0` |
| `L12` | `0.10422` | `−13.5%` | — | `37` | `0` |
| `L12S(f=0.5, p=0.5)` | `0.10555` | `−12.4%` | **`+1.3%`** | `38` | `0` |
| `L12S(f=0.5, p=0.05)` | `0.10182` | `−15.5%` | `−2.3%` | `40` | `0` |
| `L12S(f=0.7, p=0.5)` | `0.09148` | `−24.0%` | `−12.2%` | `42` | `0` |
| `L12S(f=0.7, p=0.05)` | `0.08872` | `−26.3%` | `−14.9%` | `42` | `0` |
| `L12S(f=0.9, p=0.5)` | `0.08489` | `−29.5%` | `−18.5%` | `44` | `0` |
| **`L12S(f=0.9, p=0.05)`** | **`0.08284`** | **`−31.2%`** | **`−20.5%`** | **`44`** | `0` |
| （作废）`L12M` | `0.07510` | `−37.6%` | `−27.9%` | `44` | `0` |
| （需核）`L123` | `0.07047` | `−41.5%` | `−32.4%` | `44` | `0` |

**关键事实**：
1. 默认配置 `(0.5, 0.5)` 下 `L12S` **比不做传播的 `L12` 还差 `1.3%`**——这正是缺陷被掩盖的地方：作废的 `L12M` 在同一位置报出 `−27.9%`。
2. 两个旋钮都朝同一方向起作用：给区间更多样本（`f` 大）与给传播更少风险（`p` 小）都单调改善，与 FP-BOUND-003 的结论一致。
3. 修复后 `L12S` 达到 **`−31.2%`**，发出 **`44/48`——与需要转移核的 `L123` 相同**，而 `L123` 的 `E_Q` 仍低 `10` 个点。
4. 网格只报到 `f=0.9`；`f→1` 时 B 半消失，构造失效，故不再外推。**报告整张网格而不是挑最好的格子**——事后选优正是审计警告的那类调参。

## 5. 撤回与保留

- **撤回**：`FP-BOUND-002/003` 的 `L12M` 数字（`−39.6%` / `−40.4%`）、`FP-ITER-BOUND-001/002` 的迭代数字（`36→99`、K 日程）、`FP-NET-BOUND-001` 的 `99` 步水平。这些运行使用的是未获许可的浓度步。
- **不受影响（可以继续引用）**：
  - `L1`（`−11.0%`）与 `L12`（`−13.5%`）：不使用传播，论证独立；
  - `L123` 的**推导**（恒等式 + 已知核）——它是 oracle 臂，且用核，与本次缺陷无关；但其**收益对比**要重新表述，因为对照的 `L12M` 已作废；
  - `FP-NET-BOUND-001` 的**生产者一致性**结论：网络与 numpy 在同一证书下逐格一致，这是两个生产者之间的比较，与证书用哪一个臂无关；
  - `frozen`/`L1`/`L12`/`L123` 的逐对覆盖检查（`240/240`）与风险账务。
- **下一步（按用户给的优先级）**：把 `L12S(f=0.9, p=0.05)` 接入迭代与网络格重跑；做一轮新环境族的预注册比较；证明闭合后再谈维度与 horizon。
