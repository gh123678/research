# `L1`/`L12` 的正确命题与单侧证明（应第二轮审阅要求补写）

- 日期：2026-09-14
- 依据：`results/FP-SURVIVOR-REVIEW-001/.../codex/review_report.md` §3
- 判定：**旧文的双侧/中心区间解释 FAIL**；但**实际输出的标量保证成立**，下述单侧证明支持现有数字，**不需要改算法**。

## 1. 旧文错在哪

旧文（`FP-CERTFIX-001-certificate-rederivation.md` §2 与我的勘误）称 Maurer–Pontil Thm 4 是"双侧定理"，又把所有臂统一解释成"两方向各花 `δ_pair/2`"。审阅指出：**若目标是中心区间 `|mean − μ| ≤ r`，`L12` 的两侧 union 确实是 `2δ_step`，旧解释不成立。**

**但实际输出不是中心区间。** 代码要的是

```text
|ρ_x| ≤ |mean_x| + r_x          （幅值上界，单侧）
E_Q   = max_x ( |mean_x| + r_x ) / (1−γ)
```

这才是 `LB_s = Î_s − E_Q‖Δπ_s‖₁` 所需要的量。

## 2. 正确的命题与证明（幅值目标，每个固定分布只需一个方向）

给定历史 `H` 与该对容量 `n`，记 `μ = E[Y]`、`mean` 为样本均值、`r` 为样本方差半径。**注意 `r` 对 `Y → −Y` 不变**，且 `μ` 的符号是**分布参数**，条件于 `H` 是固定的。

- 若 `μ ≥ 0`：只用 MP 的上侧方向 `μ − mean ≤ r`，得 `|μ| = μ ≤ mean + r ≤ |mean| + r`；
- 若 `μ < 0`：只对 `−Y` 用 MP（其均值为 `−μ > 0`），得 `−μ + mean ≤ r`，即 `|μ| = −μ ≤ −mean + r ≤ |mean| + r`；
- 若 `μ = 0`：所需幅值上界平凡成立。

**这不是让算法依据认证样本选符号**——算法输出仍是 `|mean| + r`；证明按**真实参数**分情况，而真实参数条件于 `H` 固定。于是

```text
Pr{ |μ| > |mean| + r  |  H, n } ≤ δ_dir
```

按 `n` 积分（首访容量随机但与取值独立），对 `d` 个对做 union：`L12` 的总失败概率 `≤ d·δ_dir = δ_step`；再按步 union 得单轨迹 `≤ δ_total`。最后由 Bellman 残差的确定性界（引理 C）得到所需的 `E_Q`。**全程没有新增浓度函数，也没有传播构造。**

## 3. 由此确定的口径（各臂的实际花费）

| 臂 | `delta_dir` | `log(2/delta_dir)` | 幅值目标的失败预算 |
|---|---|---|---|
| `frozen` / `L1` | `δ_step/(2d)` | `log(4d/δ_step)` | 至多 `δ_step/2`（保守花费） |
| `L12` | `δ_step/d` | `log(2d/δ_step)` | 至多 `δ_step`（花满） |

**"免费"的含义**：`L1`/`L12` 不额外采样、不增加名义失败预算；**不是零失败概率**。真实数值不受单/双侧解释影响——两种读法给出同一个 `log` 项（见 `FP-BOUND-002-l12m-withdrawal-and-split-repair.md` §3 的代数），差别只在**命题该怎么写**。

## 4. `frozen` 的 `Y_RANGE = 20` 不随族的 `reward_bound` 变化

第二轮审阅发现 `fixed_policy_tight_certificate` 中 `frozen` 的 `Y_RANGE` 硬编码为 `20`，不随 F2 的 `R* = 2.0` 变。**在这两个族上不构成失效**：固定对中 `−Q̂(x)` 只是平移，不影响值域长度，而

```text
range(Y_x) ≤ 2R* + γ·span(V̂) ≤ 2R*/(1−γ)
F1: 2(1.5)/0.3 = 10      F2: 2(2.0)/0.3 = 13.33      均 < 20
```

所以按族取更精细的固定对值域即可；`guard` 用的是各族的 `B = R*/(1−γ)`。**本结论不授权常数 `20` 对任意奖励/折扣泛化**，该泛化在 `R* > 3` 时不保证成立（准确说法是"上述通用值域论证不再保证 `20` 够用"，不是"每个实例必然失效"）。
