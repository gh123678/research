## 0. 设定与记号

- MDP：`S` 个状态、`A` 个动作（冻结实验中 `S=4, A=3`），折扣 `γ = 0.7`，奖励有界 `|r| ≤ R* = 1.5`。
- 目标策略 `π`（被评估、被改进的对象）；行为策略 `β`（冻结为初始策略 `π_0`，满足 `β(a|s) ≥ pi_min = 0.15`，故所有 `(s,a)` 对在平稳分布下有正访问概率）。
- 候选估计 `Qhat`：任意 `S×A` 数组，只要求**与认证数据独立**，且 `‖Qhat‖∞ ≤ B`，其中 `B = R*/(1−γ) = 5`。实现中以 `divergence_guard` 强制：`‖Qhat‖∞ > B` 时证书拒绝发出。
- 对 `x = (s,a)`，定义残差随机变量

  `Y_x = r(s,a,s') + γ·Vhat(s') − Qhat(s,a)`，`s' ~ P(·|s,a)`，其中 `Vhat(s') = Σ_{a'} π(a'|s') Qhat(s',a')`。

  关键事实：`Y_x` 的分布只依赖 `(s,a)` 与固定的 `(π, Qhat)`，**不依赖行为策略**。行为策略只影响各对被访问的次数。

- 值域（已知常数，无需估计）：`|r| ≤ 1.5`，`|Vhat| ≤ B`，`|Qhat(s,a)| ≤ B`，故

  `|Y_x| ≤ R* + γB + B = 1.5 + 3.5 + 5 = 10 =: E`。范围 `2E = 20`。

  这与封存模块的 `ENVELOPE = 10`、`Y_RANGE = 20` 一致。

## 1. 引理 A'（桥梁：链复制首访样本；替代被证伪的原引理 A）

> 原"引理 A"（每对保留前 n 次访问、`{N_x ≥ n}` 条件下 iid）经独立审读被精确反例证伪，原文删除（见 git 历史与顶部勘误）。错误在归纳的第二次迭代：`{τ_n < ∞}` 不是 `F_{τ_{n-1}}` 可测——链是否再次回到 x 取决于 `τ_{n-1}` 处抽到的后继，即 `Y_{n-1}` 本身，故无法提出 `P_x(B_{n-1})`。

**设置。** 认证数据由 `C` 条**独立**链组成，每条长度 `L`，起点从平稳分布 `μ^β` 独立抽取，按行为策略 `β` 演化。考察某对 `x`。设链 `c` 首次访问 `x` 的时刻为 `τ_c`（未访问则 `τ_c = ∞`），`G_c = {τ_c < ∞}`，首访处残差为 `Y_c`。

**新鲜抽取性质（1）（审读确认正确）。** 在 `{τ_c < ∞}` 上，`P(Y_c ∈ B | F_{τ_c}) = P_x(B)` a.s.，其中 `P_x = P(·|x)`。

**引理 A'。** 保留每条访问过 `x` 的链的**首访**残差，得样本 `{Y_c : G_c}`，容量 `N = #{c : G_c}`。则：

1. 每条链上，`G_c` 由首访**之前**的轨迹决定，而 `Y_c` 在首访时刻新鲜抽取，故 `Y_c ⊥ 1{G_c}` 且 `P(Y_c ∈ B | G_c) = P_x(B)`——这是 (1) 在 `k=1` 的合法应用（审读实测 `0.4995` 确认）。
2. 链相互独立 ⟹ 保留样本为 iid `P_x`，容量 `N` 随机且 `N ⊥ (Y_1, …, Y_N)`（`N = Σ 1{G_c}` 是访问指示的函数，而每个取值与相应指示独立）。
3. 因此对每个固定 `n ≥ 2`，在 `{N = n}` 下样本为 `P_x^{⊗n}`，MP（引理 B）条件成立；并且
   `P(失败) = E[ P(失败 | N) ] ≤ δ'`，对 `N` 积分**无 union 代价**。

**证明。** (1) 由 (1) 与 `{τ_c<∞} ∈ F_{τ_c}`；(2) 由链独立性与 (1)；(3) 由 (2) 与全期望公式。∎

**协议后果。**

1. 每对、每链取**首次访问**的残差；每对保留容量 `N_x` 随机。
2. 弃权条件：**`N_x < n_min`**（`n_min` 预登记为 2000；`N_x` 与取值独立，故任何只依赖 `N` 的弃权规则都安全）。旧的"访问总数不足 n"表述作废。
3. 每对的 MP 半径用该对实际的 `N_x`（界对一切 `N_x ≥ 2` 的实现值成立）。
4. 代价（如实）：每对有效样本量从"访问总次数"降为"访问过该对的链数"（本冻结构型下同数量级但更小）。这是保证为真的价格。
5. 备选（任务单预登记 fallback）：直接从转移核 `P(·|s,a)` 逐对采样——同样正确，但需要 oracle 核、改变数据访问声明；引理 A' 保持在行为链数据内，是更强声明。本任务采用引理 A'。

## 2. 引理 B（单对均值集中：Maurer–Pontil 经验 Bernstein）

**定理（Maurer & Pontil 2009, Thm 4，按范围 R 缩放）。** 设 `Y_1,…,Y_n` iid，取值于长度 `R` 的区间，`n ≥ 2`。记无偏样本方差 `V_n = (1/(n−1)) Σ_i (Y_i − Ȳ)²`。则对 `0 < δ' < 1`，以概率至少 `1−δ'`：

`|Ȳ − E[Y]| ≤ sqrt(2 V_n log(2/δ') / n) + (7/3) · R · log(2/δ') / (n−1)`。   (2)

（原文对 `[0,1]` 值域、单侧给出 `P(Ȳ − EY ≥ …)` 与对偶方向各 `δ/2` 的分配；本文按值域 `R = 2E = 20` 缩放，并把双侧风险合并进 `δ'` 的取法，见 §5 风险账务。）

**前提核对：** iid —— 引理 A'（对每个 `N = n` 条件成立，再对 `N` 积分）；`n ≥ 2` —— 弃权规则保证 `N_x ≥ n_min ≫ 2`；有界 —— §0 值域常数。三个前提逐条对上，不再有缺口。

**为什么不能再用旧的两步构造。** 旧 frozen 证书先估 `s_x = sqrt(E[Y²])` 再把 `2 s_x` 当作 Hoeffding 的值域参数：Hoeffding 引理要求**真实值域**，`E[Y²]` 的上界不蕴含同尺度次高斯性（反例：重尾有界变量可以有很小二阶矩和 `O(E)` 量级的尾部）。该步无法用增加数据修复。旧 empB 臂把样本方差代入普通 Bernstein 不动点（`_equilibrium`），缺 MP 修正项；新实现里宣称不变的二阶矩余量又少了 `√2`（正确余量 `(E²/2)·sqrt(2 log(1/δ')/m)` 被写成 `(E²/2)·sqrt(log(1/δ')/m)`，小了 `√2` 倍，方向是**过紧**）。这些都由引理 B 的单步构造替代。

## 3. 引理 C（Bellman 残差 → 价值误差）

定义 Bellman 算子 `(T^π Q)(s,a) = E_{s'~P(·|s,a)}[ r(s,a,s') + γ Σ_{a'} π(a'|s') Q(s',a') ]`。则 `E[Y_x] = (T^π Qhat − Qhat)(x) =: ρ_x`（Bellman 残差）。

**引理 C。** `‖Qhat − Q^π‖∞ ≤ ‖ρ‖∞ / (1−γ)`。

**证明。** `Q^π = T^π Q^π`，且 `T^π` 在 sup 范数下是 `γ` 收缩（`‖T^π Q1 − T^π Q2‖∞ ≤ γ‖Q1−Q2‖∞`，因为对每个 `(s,a)` 差值是同一分布下值函数差的凸组合乘以 `γ`）。于是
`‖Qhat − Q^π‖ = ‖T^π Qhat − ρ − T^π Q^π‖ ≤ γ‖Qhat − Q^π‖ + ‖ρ‖`，移项即得。∎

## 4. 引理 D（改进下界的有效性）

固定 `π, Qhat`，候选 `π⁺`（相对 softmax 网格中的任意一个，或它们的任意数据依赖选择——见下注）。记 `Δπ_s = π⁺(·|s) − π(·|s)`，

`Î_s = Σ_a Δπ_s(a) Qhat(s,a)`，`LB_s = Î_s − E_Q · ‖Δπ_s‖₁`。

**引理 D。** 在事件 `Ω = {‖Qhat − Q^π‖∞ ≤ E_Q}` 上，对每个状态 `s` 和**每一个**候选 `π⁺` 同时有

`A_s := Σ_a Δπ_s(a) Q^π(s,a) ≥ LB_s`。

**证明。** `|A_s − Î_s| = |Σ_a Δπ_s(a)(Q^π − Qhat)(s,a)| ≤ ‖Q^π−Qhat‖∞ · ‖Δπ_s‖₁ ≤ E_Q‖Δπ_s‖₁`。∎

**注（网格选择无额外适应性）。** 上界对固定 `(π, Qhat)` 的所有候选**同时**成立（它只使用 sup 范数界），因此在 `Ω` 上用 LB 在网格中做首通选择不消耗额外风险。

**推论（逐状态严格改进）。** 若 `min_s LB_s > 0`，则在 `Ω` 上 `A_s > 0` 对所有 `s` 成立。由性能差恒等式（从任意起始状态 `s0` 沿 `π⁺` 的折扣访问），`v^{π⁺}(s0) − v^π(s0) = E[ Σ_t γ^t A_{s_t} | s0 ] > 0`。即合取门槛通过 ⟹ 逐状态不退化且严格改进。

## 5. 定理 1（单步证书）

**协议。** 给定固定 `π, Qhat`（与认证数据独立），风险预算 `δ_step`。抽取认证批（`C` 条独立链 × `L`），按 §1 引理 A' 协议：每对、每链保留**首访**残差；记对 `x` 的保留容量为 `N_x`；若任一 `N_x < n_min`（预登记 2000）则弃权。否则对每个对 `x` 以 `δ' = δ_step/(2d)` 应用引理 B（`n = N_x`，双侧两方向各 `δ'`），得半径 `t_x`。令

`ε_res = max_x ( |mean_x| + t_x )`，`E_Q = ε_res / (1−γ)`。

**定理 1。** `P( ‖Qhat − Q^π‖∞ ≤ E_Q ) ≥ 1 − δ_step`（对随机容量亦无额外代价，引理 A' 第 3 条）。

**证明。** 引理 A' 给出：对每对 `x`、每个 `N_x = n ≥ 2`，保留样本 iid 固定 n；引理 B 在该条件下以每方向 `δ'` 控制偏差。对 `N_x` 取全期望，再对 `d` 对 × 2 方向 union：失败概率 ≤ `2d·δ' = δ_step`。联合事件上 `max_x |ρ_x| ≤ ε_res`，由引理 C 得证。∎

**风险账务（H4 可核）。** 单步：`2d` 个方向 × `δ_step/(2d)` = `δ_step`；随机容量不产生额外项。输出 `delta_each = δ'` 与每对 `N_x` 供直接加总验证。

## 6. 定理 2（多步轨迹级保证：适应性修复）

**协议。** Horizon `K` 预先冻结。第 `k` 步：

1. 已有 `π_{k−1}`（由历史 `H_{k−1} = σ(train, B_1,…,B_{k−1})` 决定）；
2. 计算 `Qhat_k = f(train, π_{k−1})`（估计器只依赖训练数据与 `π_{k−1}`，故 `Qhat_k` 是 `H_{k−1}` 可测的）；
3. 抽取**全新**认证批 `B_k`：种子计划预先固定且按步索引，`B_k ⊥ H_{k−1}`；
4. 以 `δ_k = δ_total / K` 对 `(π_{k−1}, Qhat_k)` 跑定理 1 的证书；用 LB 网格判决得 `π_k`。

**定理 2。** 设每步数据按 §1 协议、所有步的 `G_k` 都发生（否则轨迹在该步弃权停止）。则

`P( ∩_{k=1}^K Ω_k ) ≥ 1 − Σ_k δ_k = 1 − δ_total`，

其中 `Ω_k = {‖Qhat_k − Q^{π_{k−1}}‖∞ ≤ E_{Q,k}}`。在 `∩ Ω_k` 上：每一次发出的更新逐状态严格改进（引理 D 推论），整条轨迹的价值分量单调不减。

**证明。** 关键观察：在第 `k` 步，`π_{k−1}` 与 `Qhat_k` 相对 `B_k` 是**固定对象**（`H_{k−1}` 可测），`B_k` 与之独立。因此定理 1 在条件概率下成立：`P(Ω_k^c | H_{k−1}) ≤ δ_k` 几乎必然。取期望得无条件 `P(Ω_k^c) ≤ δ_k`，再对 `k` 做 union bound。∎

**与旧协议的差别（审阅第 3 条）。** 旧协议在循环外生成一次认证集，之后 12 步复用：第 `k` 步的策略 `π_{k−1}` 已经是该认证集的函数（它筛选了之前的 η），于是第 `k` 步被认证的对象依赖认证数据本身，定理 1 的条件独立性被破坏——旧固定对象证明无法覆盖。本协议以每步新批次恢复条件独立性。**η 网格选择使用同一步的 `B_k` 是允许的**（引理 D 注），因为被证对象 `‖Qhat_k − Q^{π_{k−1}}‖` 不依赖 `B_k`，选择发生在覆盖事件内部。

**保证覆盖范围的明确声明。** 定理 2 是**单条轨迹**级别的联合声明。若要 `48` 条记录 × 两臂的联合声明，需再做一层 union（例如每条记录 `δ_total/96`）；本任务默认只声明单轨迹级，跨记录联合在报告中如实标注为未分配风险。

## 7. 对照臂：最小修复的两步证书（可选）

为量化"最小修复"与 MP 的差距，保留切半结构但修正三处：

1. 每对按引理 A' 保留首访样本（容量 `N_x` 随机），按保留顺序切半：条件于 `N_x = n`，两半容量 `⌊n/2⌋` 固定、各自 iid 且相互独立（iid 样本的顺序切半）；再对 `N_x` 积分。
2. 二阶矩步（正确 Hoeffding，含 `√2`）：`Z = Y² ∈ [0, E²]`，`v_x = mean_A(Z) + E²·sqrt(log(1/δ₁)/(2m))`，`m = ⌊N_x/2⌋`，以概率 `≥1−δ₁` 上界 `E[Y²] ≥ Var(Y)`。
3. 均值步（Bernstein，条件于 half A）：对 `half B` 的 `m` 个 iid 样本，以方差上界 `v_x`、值域 `2E` 解 `t² = (2 v_x + (4/3)·2E·t)·log(2/δ₂)/m`；在 `{v_x ≥ Var(Y)}` 上 `P(|mean_B − E[Y]| > t) ≤ δ₂`。
   风险：每对 `δ₁ + δ₂ = δ_step/d`（`δ₁ = δ₂ = δ_step/(2d)`），`d` 对合计 `δ_step`。

注意在 `Var(Y)` 很小但该对恰好被访问到时，两步构造的 `v_x` 含 `E²·sqrt(·/m)` 量级余项，通常松于 MP——这正是旧线"样本方差项吃掉大头"的来源，由对照臂量化。

## 8. 本保证不覆盖什么（如实声明）

1. **不证明 Qhat 准**——只证明"若 LB 判决发出，则改进为真"（在安全事件上）。`Qhat` 的质量由 oracle 审计与网络/numpy 一致性实验另行评估。
2. **H2 的零违规不是有效性证据。** 覆盖概率是分布性质；有限记录的 0 违规是必要非充分条件（FP-TIGHT-001 已证明不成立的界也能 0 违规）。有效性由本文档的推导承担，零违规只作失败检测器。
3. **浮点。** 推导在实数域；float64 计算引入的误差由阶段 3 的高精度复算单独核查（`LB_s` 接近 0 的判决需区间/高精度复核）。数值失效步数目前**未知**。
4. **环境范围。** 4 状态 3 动作、24 个环境、行为策略 `pi_min=0.15`。跨环境声明需阶段 4 的新环境实验。
5. **样本量成本。** 每步新批次的总数据量约为旧协议的 `K` 倍量级；这是有效多步保证的诚实代价，作为主指标之一报告。
