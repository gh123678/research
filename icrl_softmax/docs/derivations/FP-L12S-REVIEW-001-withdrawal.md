## 1. 审阅的核心反对，以及我独立复核的结果：**反对成立**

审阅指出：「`V_2` 一般已依赖 `B`，后续反复用同一 `B` 估计 `V_2` 等函数，现有固定函数 Hoeffding 论证不闭合。」

**我复核后确认这是对的，并且这是我在 `L12S` 设计里的实质错误。** 机制：

```text
V_0 = max_x ε_x/(1−γ)                   条件于 A 半固定（ε 只由 A 半算出）✓
V_1(s) = ε̄(s) + γ Σ_a π(a|s)[ T^B_x(V_0) + c_0(x) ]      ← V_1 依赖 B
V_2(s) = ε̄(s) + γ Σ_a π(a|s)[ T^B_x(V_1) + c_1(x) ]      ← T^B 的被平均函数是 V_1
                                                           而 V_1 由同一份 B 算出 ✗
```

**切半只护住了 `k = 0` 这一步。** 从 `k ≥ 1` 起，`T^B_x(V_k)` 的被平均函数 `V_k` 是**同一份 B** 的函数，浓度步重新变成"对数据依赖函数用固定函数 Hoeffding"——与 `L12M` 完全同类的缺陷，只是推迟一次迭代进入。这正是审阅第 1 条说的"即使额外赠予 A/B 独立性，递推复用依然存在"。

**我此前只检查了第一步就宣布修复成立，这是错误的方法论**：一个归纳要逐项检查归纳步，而我只检查了基例。

**可直接检查的推论**：在本构造下，**只有 `n_iter = 1` 是合法的**（此时被平均的 `V_0` 条件于 A 固定、且与 B 独立）；实现用的是 `n_iter = 12`，全部落在不合法的区间。这是我可以立即验证并承认的量化指认。
