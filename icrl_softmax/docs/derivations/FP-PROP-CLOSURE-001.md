# 传播方向的关闭论证，与三名"幸存者"的前提继承审计

- 日期：2026-09-14
- 触发：第三方审阅（`results/FP-L12S-REVIEW-001/`）判 `FAIL`，`L12S` 撤回（见 [`FP-L12S-REVIEW-001-withdrawal.md`](FP-L12S-REVIEW-001-withdrawal.md)）
- 目的：① 把"无模型传播"这个方向**按论证关闭**，而不是按失败记录关闭；② 用同一个教训审计幸存的三项，确认它们不属于同一缺陷类。

---

## 1. 为什么这个方向应当关闭（而不是再修一次）

**共同失败模式（三次同源）**：把一个**由数据算出的函数**送进只能用于**固定函数**的浓度不等式。

| 次 | 构造 | 缺陷所在 |
|---|---|---|
| 1 | `L12M` | `W_k` 由同一批后继观测递推，第 1 次迭代即不合法 |
| 2 | `L12S` | 切半只护住 `k = 0`；`V_1` 已依赖 B，第 2 次迭代起不合法 |
| 3 | 本次 | 合法子集（`n_iter = 1`）**无价值** |

**第三条是关键，它把方向关死**：

- `n_iter = 1` 时，`V_0 = max_x ε_x/(1−γ)` 条件于 A 半固定、`B ⊥ A`，故 `T^B(V_0)` 的浓度步**合法**。但给出的界是
  `V_1(s) = ε̄(s) + γ(V_0 + c_0)`，
  而均匀界就是 `V_0`。一次迭代**不改进**均匀界——它只是从一个上界往下走的第一步，而我们要的是走到不动点。
- 要走到不动点，每步都需要"被平均的函数与用于估计它的样本独立"。在**单一认证批**下，唯一的办法是把每对的样本切成 `K` 份、第 `k` 次迭代只用第 `k` 份。此时区间只能用第 0 份 → 半径按 `√K` 膨胀。
- **这个代价已经实测过**：`measure_fp_bound_005.py` 显示连 **2 路**切分（`√2`）的代价都超过传播带来的收益，而合法版本需要 `K = n_iter + 1` 路。

**结论**：合法 ⟹ 无价值；有价值 ⟹ 不合法。方向的关闭不是"我们没试出来"，而是"合法子集是空集"。

**若有人要第四次尝试**，起点必须是**新的构造**，且需先回答一个问题：*在没有独立样本可切的前提下，哪个量可以既被估计、又不进入对它自身的估计？* 本项目目前的答案是"没有"。

## 2. 前提继承审计：三名幸存者是否属于同一缺陷类？

审阅暴露的失效模式是：**验证套件检查了算术与覆盖，却没有检查归纳步的前提是否被继承**（`verify_fp_bound_002.py` 对一个不合法的构造报了 PASS）。因此对幸存三项逐项做同一检查：

| 项 | 是否含"数据依赖函数 → 浓度不等式" | 判定 |
|---|---|---|
| **`L1`** 包络 `E_eff = R* + γ‖V̂‖∞ + ‖Q̂‖∞` | **否**。`V̂、Q̂` 是证书的**输入**，与认证批独立；`E_eff` 是它们的确定性函数，不进入任何"由同一批数据估计自身"的回路 | **通过** |
| **`L12`** MP 区间（`δ′ = δ_step/d`） | **否**。无迭代、无递推；每个区间只由该对**自己**的 iid 样本算出，被估的对象是常数 `ρ_x` | **通过** |
| **`L123`** 已知核精确传播 | **否**。传播用**已知**的 `P`，不做任何估计；进入浓度步的只有逐对区间 | **通过** |

三项都不含递推估计，因此**不属于** `L12M`/`L12S` 的缺陷类。这是"用审阅的教训反过来检查幸存者"的结果，而不是"因为它们没被审阅所以大概没问题"。

**但必须同时说清**：这项审计**不构成独立验证**。它只说明三项**没有**被这个特定缺陷污染；它们仍然是同执行者验证的初步结果。
