# 研究材料索引

了解项目现在做到哪里，请先读 [当前研究状态](../ACTIVE_WORKSPACE.md)。

| 材料 | 用途 |
|---|---|
| [正式任务](research_tasks/README.md) | 查看某一次研究的问题、方法、验收依据与记录 |
| [研究报告和推导](research_branches/) | 查看支持结论的具体证据，包括失败结果 |
| [设计](superpowers/specs/) 与 [执行计划](superpowers/plans/) | 追溯各任务当时采用的方案 |

| [保留的历史推导](../论文_草稿/README.md) | 查看旧方法的推导、引用和复核记录 |

旧任务中出现的“当前进展”“下一步”只对应当时的研究阶段。最新状态统一以入口页为准；历史失败、修复和验证记录保留原文。

2026-09-12 已按用户批准的 89 项清单删除过时材料，包括被后续研究取代的教学摘要、旧路线评价、论文展示稿、专用构建脚本、临时导出件和归档展示副本。当前阅读入口已整理，研究依据保留原位置。
