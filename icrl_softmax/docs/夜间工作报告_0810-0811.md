## 1. 背景与问题设定

### 1.1 两条论文线的对照

**03 论文（Liang & Lai, ICRL）——线性 attention**：
单层块 `Hout = H + (1/n)·V H (Hᵀ P H)`。通过结构化参数化 `P₁₂, V₂₁` 可以**精确实现 SARSA**：
- attention score `A[s] = <P₁₂ w~, H[:,s]>` 是 bilinear 的（含 `w`），这正是 `wᵀφ` 内积；
- 读出 `Σ δ_t φ_t` 由 V 的线性块完成。
**线性 attention 的 score 天然是二次型，能表达 `wᵀφ`，所以能精确做 SARSA。**

**04 论文——softmax TD 评估**：
`K[j,t] = softmax(<x_j, x_t>)`，`v += K @ δ`。评估定义在轨迹状态上，用 TSM（列左移）做 bootstrap。**`w` 完全不进 scores（特征核）**，所以权重稳定、训练容易。

**advisor 的问题**：04 的 softmax 机制（评估）很好，但能不能在它上面做**策略改进**？也就是把"评估"升级成"评估 + 改进"的闭环。

### 1.2 已有的 negative result（本会话早期确立）

单层 softmax attention，**线性 V、固定特征核、`w` 不进 scores**，它的输出是特征的 softmax 加权平均：

```
输出 = Σ_t attn_t · (V H[:,t])，attn_t = softmax(<φ_query, φ_t>)
```

它**无法**表达 SARSA 的 `Δw = Σ_t δ_t φ_t`：
- 需要逐项乘积 `δ_t × φ_t`（跨行乘积，线性 V 做不到）；
- 需要 `wᵀφ`（bilinear，`w` 必须进 scores）；
- softmax 归一化会把未归一化的 `Σ δ_t φ_t`（δ 可正可负）破坏成加权平均。

**这是精确意义下的 negative result**：04 的"纯 softmax 评估"无法直接升级成 SARSA 改进。

### 1.3 方案 C 的决定

既然精确 SARSA 做不到，advisor 讨论后的方向是 **C：从根上重设 softmax 参数化**——把任务拆成：
- **评估**：用 04 的 softmax-TD 进 attention（可学习），输出当前值；
- **改进**：用线性读出 `dw = (α/n)·Σ δ_t φ_t`，其中 `δ` 完全由评估的行给出（**不含 `w`**）。

这样整个模型**没有 bilinear、`w` 不进 scores**，是 softmax 可实现的结构。这就是 **C3（SoftmaxEvalImprove）**。

## 2. 出发点：C3 已经成功（多 seed 复现）

C3 架构（`model.py::SoftmaxEvalImprove`）：

- prompt `Z (d+3, n+1)`：特征 `d` 行 + 奖励 1 行 + target 1 行（TSM 内部）+ current 1 行（跨帧评估 memory `v_state`）；
- 层更新：`Zhalf = Z + V Z softmax(ZᵀAZ + M)`，target 行 ← `γ·current` 列左移（04 TSM）；
- 输出：`v_pred`（评估）+ `dw = (α/n)·φ @ (R + γv[1:] − v[:n])`（改进读出）。

teacher 目标（numpy 渐进机制）：跨帧维护 `v_state (nS,nA)`，每帧对轨迹访问的 `(s,a)` 做一步在线 TD，改进 `dw_tgt = (α/n)·Σ δ_t φ_t`，评估监督 `v_tgt = v + (α_eval/n)·δ`。

**闭环结果（3 seeds）**：

| seed | 模型 final | teacher final | oracle（value iteration） |
|---|---|---|---|
| 0 | 0.2569 | 0.2557 | 0.5401 |
| 1 | 0.2517 | 0.2548 | 0.5401 |
| 2 | 0.2422 | 0.2548 | 0.5401 |

（`--self-eval 1`：模型自维护评估 memory，0.2517，也能工作。）

**关键观察**：模型几乎**完美匹配 teacher**。说明模型把 teacher 的机制（on-policy 渐进评估 + 线性读出）学得很好。**所以 C3 的 0.25 上限不是模型的表达力问题，而是 teacher 机制本身的固有上限。** 要提高，必须改进 teacher 机制。

## 3. 核心发现一：改进死锁（on-policy bootstrap）

### 3.1 为什么 C3/online 停在 0.23–0.27

C3 的改进残差是 **on-policy** 的：`δ_t = R_{t+1} + γ·v(s_{t+1},a_{t+1}) − v(s_t,a_t)`，其中 `(s_{t+1},a_{t+1})` 是**实际采到的**动作。

当评估 `v → Q^π`（当前行为策略的价值）时，对 on-policy 数据：

```
E[δ | s,a] = Q^π(s,a) − E[R + γQ^π(s′,a′)] = Q^π(s,a) − Q^π(s,a) = 0
```

**改进梯度 `Σ δ_t φ_t` 的期望为零。** `w` 只被噪声推动，做随机游走，改进停止。

这不是收敛速度问题。实测排除：

| 变体 | 说明 | 400 帧 final |
|---|---|---|
| online | 原 C3 机制（on-policy bootstrap） | 0.2355 |
| online_big | 把评估更新步长放大 20 倍（加速收敛） | 0.0634（震荡更差） |

加速评估反而更差，说明瓶颈是机制，不是收敛速度。

### 3.2 对照：standard SARSA 为什么不死锁

`train.py::sarsa_teacher`：

```
δ_t = R_{t+1} + γ·φ(s_{t+1},a_{t+1})·w − φ(s_t,a_t)·w
```

**bootstrap 用当前 `w` 的线性价值**（不是独立评估 memory）。`w` 是改进的目标也是评估的参数，单参数实现"评估 + 改进"。SARSA 是策略迭代式的：`ε-greedy` 在 `w` 上产生新行为，SARSA 继续朝新行为的 Bellman 残差推 `w`，单调改进。

- sarsa 闭环（400 帧）：**0.41–0.46**。
- online（C3 机制）：**0.23–0.27**。

**差距的根源**：C3 的独立评估 `v_state → Q^π` 只反映当前策略的价值，`δ` 的期望归零；SARSA 的 `w` 自己就是价值，朝贪心方向迭代。

### 3.3 一个反直觉的失败：`fullv`

我试过"把改进 bootstrap 换成 `max` 但当前项用 `v`"：

```
δ = R + γ·max_a′ v(s′,a′) − v(s,a)     # fullv
```

这也死锁（0.2406）。原因：`w` 学的是"改进量"（`T_max − v`）的回归系数，行为 `ε-greedy` 在 `φw` 上 = greedy 在**改进量**上，而不是在**价值**上——方向错了。**要正确的策略迭代，改进必须用 TD 误差（当前项是 `w` 自己的价值），不是改进量。**

## 4. 核心发现二：max bootstrap 突破死锁（超过 SARSA）

### 4.1 两个成功的机制

**improve_max**（独立评估 memory 的 max）：

```
δ = R_{t+1} + γ·max_a′ v_state(s′,a′) − φ(s,a)·w        # 目标用 max，当前项用 w（TD 误差）
v_state 更新：on-policy SARSA 一步（评估保持稳定）
```

**qlearn_direct**（直接用当前 `w` 的价值做 max，半梯度 Q-learning）：

```
δ = R_{t+1} + γ·max_a′ φ(s′,a′)·w − φ(s,a)·w            # 完全不用独立评估 memory
```

### 4.2 结果（400 帧闭环，多 seed）

| 机制 | seed0 | seed1 | seed2 | seed3 |
|---|---|---|---|---|
| sarsa（03 on-policy） | 0.4107 | 0.4123 | 0.4333 | 0.4620 |
| online（C3 机制） | 0.2355 | — | — | — |
| **improve_max** | 0.4111 | 0.4532 | 0.4538 | 0.4624 |
| **qlearn_direct** | 0.4263 | 0.4649 | 0.4524 | 0.4499 |

oracle-true（value iteration）≈ 0.52–0.54；random ≈ 0。

**三条结论**：

1. **max bootstrap > on-policy bootstrap**：`qlearn_direct`（0.45±）与 `sarsa`（0.41–0.46）持平或略好，`improve_max` 也稳定超 SARSA。
2. **独立评估 memory 对改进不是必要的**：直接用 `φw` 的 max（qlearn_direct）和用 `v_state` 的 max（improve_max）效果相当。
3. **改进死锁的修复是"贪心目标"**：bootstrap 必须反映 `π′ = greedy` 的方向，而不是当前行为 `π`。

### 4.3 为什么 max 能突破死锁

对 on-policy 数据，`E[δ_max] = E[R + γ·max_a′ Q^π(s′,a′)] − Q^π(s,a) = (T^max Q^π)(s,a) − Q^π(s,a) ≥ 0`，当行为不是最优时**严格为正**——改进梯度期望非零，`w` 被持续推向贪心方向。这是策略改进定理 + 半梯度策略评估的组合。

## 5. 核心发现三：softmax 的 bilinear 障碍（为什么模型学不出来）

### 5.1 策略迭代需要 bilinear

4 节的机制全部要求改进残差含 **`φ(s,a)·w`**（当前值项）。它是 `w` 与特征的 bilinear 内积。

- **精确表达**：需要 `w` 进 scores（像 03 的 `P₁₂ w~`），或读出行含 `φφᵀw`（特征二阶矩 × `w`）。两者都是二次型，**线性 softmax 读出做不到**。
- **03 论文能做的原因**：它的 attention score `HᵀPH` 本身是二次型（bilinear），`w` 通过 `P₁₂` 进 score。04 的 softmax 用特征核避开 `w`，代价就是失去了 SARSA 的改进能力。

### 5.2 实证：模型学"v→w 的桥"失败（C3-v2）

我构造了 **C3-v2（SoftmaxEvalImproveV2）**：prompt 加一行 **max 目标** `M_t = max_a′ v_state(s′,a′)`（numpy 预计算，`w` 无关），模型读出仍用 current 行：

```
delta = r + γ·M − v[:n]              # 读出用 v 行（w 无关）
dw     = (α/n)·φ @ delta
```

teacher 监督 `dw_tgt = (α/n)·Σ(R + γM − φ·w)φ`（improve_max，含 `w`）。**期望**：模型通过学 `v 行 ≈ φ·w` 让读出逼近 TD 误差。

结果（训练 loss 下降、但闭环崩溃）：

| 变体 | 训练 | 模型闭环 final | teacher 闭环 final |
|---|---|---|---|
| lam_eval=1.0, v-tgt=qpi | 0.00031 | **0.0048** | 0.3619 |
| lam_eval=0.0（只监督改进） | 0.00093 | **−0.0202** | 0.3850 |
| lam_eval=1.0, v-tgt=φw | 0.3529 | **0.0677** | 0.4149 |

模型全部远低于 teacher（0.36–0.41），有的甚至低于 random。

**原因**：`φ·w` 依赖当前 `w`，而 `w` 不在模型输入。模型只能从"与 `w` 无关"的输入（`v_state` 行、`M` 行、特征、奖励）推断改进量。`v_state`（渐进、`α_eval/n` 步长很慢）追不上 `φ·w`，`M` 也依赖 `v_state`，误差随闭环滚雪球。**这是 softmax"`w` 不进输入"架构的固有代价——改进需要 `w` 的信息，但架构不给模型提供 `w`。**

### 5.3 补充：one-step-greedy 基线

`greedy on 单步期望奖励` 的闭环 return = **0.376**。C3（0.25）低于它——说明 C3 的改进不是"单步贪心"水平的干净解，而是"on-policy 渐进评估 + 噪声驱动"的失衡态。这更衬托出 max bootstrap（0.42+）的机制价值。

## 8. 结论：回答 advisor 的问题

> **在 softmax attention 里，能否进行 policy improvement？**
> （注：这是 Part I 的结论。后半夜 B1 续篇把它修正为更乐观的版本——见第 15 节。
> 本节的"完整策略迭代卡在 bilinear"仍成立，但 B1 发现"改进算子本身 softmax 可做"。）

**能，但分两个层次：**

1. **能做一个"评估驱动的有限改进"**（C3）：把 04 的 softmax-TD 评估放进 attention（可学习），配上线性改进读出（不含 `w`），闭环 return 从 0.10 提到 0.25，多 seed 稳定，模型自维护评估也能工作。**这证明"评估进 attention"是 softmax 架构内可行的一步。**

2. **完整策略迭代（超 SARSA）需要 bilinear**：`max bootstrap + TD 误差` 把上限从 0.25 提到 0.42–0.46（超 SARSA），但改进残差必须含 `φ(s,a)·w`。这个 bilinear 在 softmax 的线性读出里**无法精确表达**，而且让模型从"与 `w` 无关的输入"学习它（C3-v2）**训练失败**。

**一句话**：softmax attention 能做评估和线性读出层面的策略改进，但"完整的、超过 on-policy 半梯度水平的策略迭代"卡在 bilinear 障碍上——`w` 必须进 scores（03 的方式）或近似处理，而那是 softmax 训练不稳定的根源。

| 工作 | attention | 做的是什么 |
|---|---|---|
| Wang et al. ICLR 2025 | 线性 | 只做 **policy evaluation**（in-context TD，首个构造性证明） |
| Xie & Liu, arXiv 2605.07333（= 04 论文） | **softmax** | 只做 **policy evaluation**（weighted softmax TD in kernel space，首个去掉线性 attention 假设） |
| Liang & Lai, arXiv 2605.05755（= 03 论文） | 线性 | 做到 **policy improvement**（semi-gradient SARSA / actor-critic，首个收敛性保证） |
| S-ICQL, ICLR 2026 | softmax（实用） | 工程框架，非机制证明 |

**结论：softmax attention + policy improvement，还没有人做。** 03 只在线性（未归一化）

`Σ_j (H_jᵀPH_t)(V H_j)`**，所以改进步 `Δw = Σδφ = Σφ(r+γM) − ΦᵀΦw` 中的特征-特征
相关项 `ΦᵀΦw`（半梯度 SARSA 的核心）能自然出现；**softmax 把权重归一化成凸组合，
`ΦᵀΦw` 项被吃掉**——这就是 softmax 做改进难的根本机制原因。

## 11. 决定性诊断：softmax 的 max 部分完全可行，死锁根因是"当前值项"

### 11.1 实验（`diag_b1.py`，60 MDP，400 帧）

隔离 softmax 损失的每一部分：

| 机制 | 说明 | 400 帧 final |
|---|---|---|
| **wval** | `δ = r + γ·max v_state − φ·w`（improve_max，线性可表达） | **0.4236** |
| memval | `δ = r + γ·max v_state − v_state(s,a)`（当前值用 memory） | **0.2125** 死锁 |
| noval | `δ = r + γ·max v_state`（去掉当前值项） | **0.2286** 死锁 |
| **softmax_max** τ∈{0.1,0.3,1,3} | wval 但 max 换成低温 softmax over `v_state(s′,·)` | **0.422/0.436/0.419/0.431** |
| **qlearn_soft** τ∈{0.1,0.3,1,3} | Q-learning max 用 softmax over 动作特征代理 | **0.436/0.399/0.395/0.411** |

（oracle 0.5353；random ≈ 0）

### 11.2 三条硬结论

1. **softmax 的 max/argmax 部分完全可行**：温度退火的 softmax 期望代理 max
   （`Σ_a softmax(v_a/τ)·v_a`）在闭环里保持 0.42+，且**对温度不敏感**（τ 从 0.1 到 3
   全通过）。`softmax ≈ argmax` 是 softmax attention 做策略改进的天然武器。
2. **死锁的唯一根源是当前值项必须是 `φ·w`（活的 w）**：换成 memory 值（memval）
   或去掉（noval）都死锁回 0.21–0.23。这和 Part I 的 `fullv` 失败互相印证。
3. 因此 **B1 的正确定位不是"softmax 做不了 max"，而是"让 w 进机制"**——max 已经能
   由 softmax 提供，缺的是 `φ·w`。

## 12. C3-v3：给定收敛值 φ·w，softmax 模型实现 Q-learning 改进（成功）

### 12.1 关键洞察：C3-v2 死锁的根因是 M 用了滞后的 memory

Part I 的 C3-v2 用 `M = max over v_state`（每帧只加 `α_eval/n·δ` 的滞后 memory），
闭环里 `v_state` 远未收敛到 `φ·w` → 死锁。**C3-v3 修正：M 直接取活 w 的价值
`M_t = max_a′ φ(s′,a′)·w`（Q-learning max）**，当前值行喂精确 `φ·w`，v 监督到 `φ·w`。

```
teacher: dw = (α/n)·Σ (R + γ·max_a′ φ(s′,a′)·w − φ(s,a)·w) φ(s,a)   == qlearn_direct
```

### 12.2 结果（`train_c3_v3.py` + `evaluate_c3_v3.py`，100 MDP 闭环）

训练 loss 收敛到 ~1e-5 量级（模型精确学到目标）。闭环：

| 配置 | 模型 final | teacher final | oracle |
|---|---|---|---|
| seed0, self-eval=0, 400 帧, hard max | **0.4266** | 0.4422 | 0.5283 |
| seed0, self-eval=0, 400 帧, softmax max τ=0.3 | **0.4206** | 0.4519 | 0.5283 |
| seed1, self-eval=0, 400 帧, hard max | **0.4395** | 0.4653 | 0.5354 |
| seed1, self-eval=0, 400 帧, softmax max τ=0.3 | **0.4321** | 0.4661 | 0.5354 |
| seed2, self-eval=0, 400 帧, hard max | **0.4282** | 0.4070 | 0.5325 |
| seed2, self-eval=0, 400 帧, softmax max τ=0.3 | **0.4420** | 0.4279 | 0.5325 |
| **3 seed × 2 max 型 均值（同 ckpt，独立 MDP/初始化）** | **0.4315** | 0.4434 | 0.5323 |
| seed0, self-eval=0, 200 帧（中程曲线） | 0.3845 | 0.3615 | 0.5369 |

**模型紧贴 teacher（6/6 配置均 0.42–0.44，均值 0.4315），双双达到 numpy Q-learning
水平，超过 one-step-greedy（0.376），接近 oracle（0.53）。** 随上下文长度单调改善：
200 帧 0.38 → 400 帧 0.43（闭环 in-context 学习，改进随 context 变长而增强）。
对比：C3 死锁 0.25，C3-v2 负结果 0.005–0.07。**跨 seed 完全稳定**——同 ckpt 在新
随机 MDP/特征/初始 w 上，模型与 teacher 的差距恒定在 ±0.02 以内。

**这是第一次在 softmax attention 里实现 Q-learning 式 policy improvement**（在我们的
设定下）。实现方式完全是 softmax 可表达的：
- **max bootstrap**：温度退火 softmax over 动作特征（§11 已验证）；
- **改进读出**：`dw = (α/n)·φ@(r + γM − v_row)`，线性读出（未归一化 `Σδφ`，本就可表达）；
- **当前值 `φ·w`**：由评估状态提供（04 式 softmax-TD 评估收敛后的值）。

## 13. 自包含闭环失败：模型是"copy 器"，评估漂移（`diag_selfeval.py`）

### 13.1 失败现象

模型自己维护评估（self-eval=1：`v_state := 模型 v_pred`）崩：

| 配置 | 模型 final | teacher final |
|---|---|---|
| self-eval=1, v_state 初始 0, 200 帧 | 0.1372 | 0.3722 |
| self-eval=1, v_state 初始 0, 400 帧 | 0.1491 | 0.4290 |
| self-eval=1, v_state 初始 φ·w | **0.0399** | 0.3178 |

连 teacher（改进用精确 `φ·w` 当当前项，只有 M 用评估状态）在 self-eval=1 都掉到
0.32——**M（max 目标）只要来自非收敛的评估状态就坏**。

### 13.2 诊断：模型是完美 copy 器，漂移是 copy 误差累积

追踪 `|v_pred − v_in|` 与 `|v_state − φ·w|`：

```
step    0  |v_state−φ·w| 0.0000   |v_pred−v_in| 0.0136
step   50  |v_state−φ·w| 18.16    |v_pred−v_in| 0.0097
step  100  |v_state−φ·w| 42.70    |v_pred−v_in| 0.0187
```

**`|v_pred − v_in| ≈ 0.01`**：模型把评估输入行几乎完美复制。因为 `w` 不在输入，
模型无法重新推导 `φ·w`，训练时 `v_in = φ·w`，复制就是最优解。闭环里 `v_in` 一旦漂移，
模型忠实复制漂移，误差线性累积、无修正机制。**这是"`w` 不进输入"架构的固有死结。**

## 14. C3-v4：bilinear 障碍是"部分可表达"，不是"完全不可表达"

### 14.1 实验：把 w 放进 prompt，训练时 v_in 注入噪声，逼模型用 w 重推导 φ·w

| vnoise | vloss 地板 | 说明 |

## 15. 更新后的结论：精确边界

> **在 softmax attention 里，能否进行 policy improvement？**

**能，而且比 Part I 判断的更乐观。精确边界是：**

1. **改进算子本身完全 softmax 可实现**：max bootstrap（温度退火 softmax over 动作
   特征）+ 线性改进读出 `Σδφ`，闭环 0.42–0.45（模型匹配 numpy Q-learning，超单步
   贪心 0.376）。**这是 03（线性）做到、04（softmax）没做到、没人做过的部分。**

2. **前提是评估值 `φ·w` 是收敛的**：改进残差 `δ = r + γM − φ·w` 的当前值项必须是
   活的 `w` 的价值，不能是滞后的 memory（滞后 → 死锁 0.21）。

3. **卡点精确在"模型自己维持 φ·w"**：`w` 不进输入 → 模型只能复制评估行 → 闭环
   漂移（self-eval=1 崩）；`w` 进输入 → 单层 softmax 只能**部分**重推导 `φ·w`
   （R²≈0.92），残差仍累积。**根因是 softmax 归一化吃掉未归一化的 `ΦᵀΦw` 项**
   （03 用线性未归一化 attention 正是为了这一项）。

**一句话**：softmax attention **能做** policy improvement 的"贪心化"（max bootstrap +
读出），达到 numpy Q-learning 水平；但**全自包含**（连评估一起在 softmax 模型里闭环）
被"评估值重推导的残差"卡住。这个边界比"完全做不了"乐观，也比"全做成了"诚实。

## 17. diag_attimprove：把 TD 误差放进 score 的"归一化可表达算子"也死

### 17.1 设计动机

前面确认"模型无法重推导 `φ·w`"（bilinear 障碍）。但有一个**真正可表达**的变体
没测过：让 TD 误差直接进 **score**，输出是 softmax 加权的特征和：

```
Δw ∝ Σ_j softmax((r_j + γ·M_j − w·φ_j) / τ) · φ_j
```

- score 里的 `w·φ` 是 bilinear（query 放 `[w, 1]`，key 放 `[φ, r, M]` → 精确可表达）；
- 输出是**归一化的**（softmax 能做）、**自包含的**（w 进 score）；
- 温度退火 τ→0 时 softmax ≈ argmax → 选 TD 误差最大的转移朝它推。

三种模式：`att_w`（无奖励对照）、`att_td`（δ 进 score，M 用 hard max）、
`att_td_softmaxM`（M 也用低温 softmax over 后继动作值，全 softmax 可表达）。

### 17.2 结果（60 MDP，400 帧，oracle 0.5353）

| 模式 | τ=0.05 | τ=0.2 | τ=1.0 |
|---|---|---|---|
| att_w | 0.0116 | −0.0101 | −0.0291 |
| **att_td** | **0.0481** | 0.0049 | −0.0091 |
| att_td_softmaxM | −0.0137 | −0.0161 | 0.0157 |

**全灭**（最好 0.048，贴着随机）。

### 17.3 为什么：softmax 输出是"正归一化凸组合"

softmax 权重满足 `a_j ≥ 0, Σa_j = 1`，这从结构上杀死策略改进需要的 `Σδφ`：

1. **带符号贡献不可表达**：`δ_j < 0` 的转移得不到"负推"（权重只能趋于 0，不能为负）。
   真正的半梯度需要 w 沿 `−φ_j` 推（`δ·φ` 可正可负）。
2. **量纲被归一化锁死**：更新总量恒为 α 级，不随 `|δ|` 缩放。误差大的转移和误差小的
   转移贡献被压平。
3. **低温极限退化成单秩**：τ→0 变成"选最大 δ 的一个转移，朝它的特征推"——rank-1
   更新，无法向 Q* 收缩（contrastive/拒绝采样式，不是梯度式）。

**这是干净但需要修正的负结果**：就算 score 里的 `w·φ` 精确可表达（query×key
bilinear），**纯 softmax 凸组合**（权重 = `softmax(δ/τ)`，没乘 δ）把线性 δ 结构
破坏成凸组合。策略改进要的是**未归一化的 Σδφ**（δ 带符号、线性缩放）。但"凸组合"
不是障碍的全部——**score-scaled（权重乘回 δ）的 softmax 就绕开了，见 §17.4。**
这从机制上解释了为什么 03 论文用**线性未归一化** attention（`Σ(HᵀPH)(VH)`）；
softmax 要等价，需给权重加线性缩放。

---

## 17.4 边界修正（diag_attlin.py）：score-scaled softmax 在 τ→∞ 精确=半梯度

att_td 用**纯凸组合权重**（`softmax(δ/τ)`）死。补测**乘回 δ 的变体**：

```
att_td_lin: Δw ∝ Σ_j δ_j · softmax(δ_j/τ) · φ_j
```

**关键理论点：当 τ→∞，`softmax(δ_j/τ) → 1/n`（均匀），算子精确退化为半梯度
`(1/n)Σδφ`。** 所以"softmax 权重"本身不破坏线性结构——只有"纯凸组合（无线性
缩放）"才破坏。**score-scaled attention（权重乘回 score 值 δ）在高温极限就是
精确策略改进**，不需要放弃 softmax。

结果（`diag_attlin.py`，60 MDP，400 帧，4 seeds；qlearn=精确半梯度上界 0.428–0.461）：

| 机制 | τ=0.1 | τ=1 | τ=5 | τ=50 |
|---|---|---|---|---|
| **att_td_lin**（×δ 加权） | 死 | 弱 | **0.43–0.48** | **0.44–0.48** |
| **att_td_tanh**（tanh 门控，×τ 补偿） | 0.20–0.29 | **0.38–0.48** | **0.42–0.45** | **0.40–0.48** |
| **att_td_sig**（sigmoid 门控，×2τ 补偿） | 0.27–0.34 | **0.39–0.44** | **0.42–0.44** | **0.39–0.45** |

（门控行是**步长补偿后**的数据——`×τ`/`×2τ` 抵消 `tanh(δ/τ)≈δ/τ` 的 1/τ 衰减，
见 §17.6。补偿前高温 τ=5/50 全死：tanh 0.28–0.33/0.07，sig 0.23–0.27/0.02–0.04。）

三条机制结论：

1. **score-scaled softmax = 半梯度的高温极限**。att_td_lin 在 τ≥5 匹配甚至略超
   qlearn（seed1 τ=5 达 0.484 vs qlearn 0.428）。**改进算子可以在 attention 权重里
   实现（不一定要 C3-v3 的线性读出头）**——这是对"softmax 做不了改进"的直接反例。
2. **带符号门控（tanh/sigmoid，无竞争归一化）补偿后全温闭环 0.39–0.48** →
   障碍精确落在**低温** softmax 的**竞争性列归一化 + 无线性缩放**（winner-take-all
   让权重互相挤压、吃掉符号；高温一阶线性化不压符号，§17.7），不是 softmax 家族
   非线性本身。门控带符号（∈(−1,1)），天然承载 Σδφ（架构 R²≈0.995，§17.6）。
3. **低温 τ=0.1 门控反降**（0.20–0.34）：饱和区 `tanh(δ/τ)→sign(δ)`，×τ 补偿把
   步长缩小 τ 倍——补偿公式只在线性区（|δ|<τ）正确，这是门控 vs 精确半梯度的
   唯一代价（幅度截断）。

**对边界的影响**：§17 需修正——**改进算子层面 softmax 完全能做**（score-scaled
softmax 高温极限=半梯度；门控也行）。**剩下的、也是唯一的障碍仍是评估值自包含**
（块内重推导 `φ·w`，bilinear R²≈0.92，§14/§18）。卡点从"改进算子 + 值自包含"
**收窄到"只有值自包含"**。

## 17.5 架构可表达性（diag_attlin_arch.py / diag_firstorder.py）：两条路殊途同归

**问题**：§17.4 证明 att_td_lin 机制可行（τ≥5 闭环 0.43-0.48）。但机制可行 ≠
单层块可表达——块输出 `Σ_j attn_j·(VH)_j` 的 V 是全局线性，无法逐 token 缩放。
测：固定特征 φ、随机 δ，`attn = softmax(δ/τ)`（softmax 最优能给：δ 进 score
线性投影），V 用**闭式最小二乘**（无梯度，确定性），报三种目标可达 R²。
**数据复核（diag_firstorder.py，float64）：arch 原表（torch float32）高温列全是
精度伪影**——均匀 O(1) 项淹没 O(1/τ) 信号，float32 解 ill-conditioned 最小二乘
爆炸，把"精确"误报成"崩"。float64 下 t_scaled/t_lin 都**单调升到 1.0**：

| 目标 | τ=0.3 | τ=1 | τ=3 | τ=5 | τ=20 | τ=200 |
|---|---|---|---|---|---|---|
| t_conv = Σ softmax(δ/τ)φ | ~1.0 | ~1.0 | ~1.0 | 1.000 | 1.000 | 1.000 |
| t_scaled = Σ δ·softmax(δ/τ)φ | 0.935 | 0.910 | 0.961 | 0.983 | 0.999 | 1.000 |
| t_lin = Σ δφ（=Φᵀδ） | **0.326** | **0.675** | **0.944** | **0.979** | **0.999** | **1.000** |
| 线性读出头 t_lin（C3-v3） | — | — | — | — | — | **1.0000** |

（t_conv 行是 **tautology**：块输出 φ-列就是目标本身，任何 τ 都 R²=1，不携带信息。
arch 原表把 t_conv/t_scaled/t_lin 三行高温全误报成"崩"。可表达性只看 t_lin/t_scaled。）

**三条机制结论**：

1. **线性读出头精确 = 半梯度（R²=1.000）**。C3-v3 的 `dw=(α/n)Φᵀδ` 是显式精确实现，
   无需任何近似。
2. **softmax 块对带符号改进（t_lin）的表达随 τ 单调升到 1.0（0.33→1.00）**——高温下
   `attn ≈ 1/n + (δ_j−δ̄)/(nτ)` 一阶线性化，块输出**隐含**出现 `Σδ_jφ_j` 项（因为
   `t_lin = [Σ(δ_j−δ̄)φ_j] + δ̄·[Σφ_j]`，两项都在读出 span 内）。这就是 att_td_lin
   τ≥5 闭环的机制，与 C3-v3 在 τ→∞ **精确重合**。**没有"最优窗"**：τ→∞ 精确极限
   （float64 达 R²=1.0），只有高 τ 数值上对精度敏感（float32 崩，SNR→0）。
3. **低温（τ=0.3）t_lin 仅 0.33**：winner-take-all 凸组合权重（无线性缩放）做不了
   带符号 Σδφ——**唯一的结构死区**。t_scaled 0.93 偏高，因 δ 与 softmax 权重单调
   正相关时凸组合能部分捕获 δ 缩放。

**架构结论（统一）**：**两条正结果不是两条路，是同一条路的两种实现**——改进的
本质是半梯度 `Σδφ`（带符号、线性缩放）；C3-v3 用线性读出头**显式**实现，
att_td_lin 用高温 softmax 权重的一阶项**隐式**实现。**符号障碍是低温
（winner-take-all）现象**：高温下 softmax≈均匀+带符号一阶项，不再是"有害的凸组合"。
值自包含（§14/§18）仍是唯一卡点。

## 17.6 带符号载体光谱：门控的架构验证 + 步长补偿（diag_attlin_arch.py / diag_attlin.py）

**问题**：§17.4 门控（tanh/sigmoid）补偿前高温死（τ=50 → 0.02–0.07），低温活
（0.40–0.48）。是表达力问题还是步长问题？用架构闭式 R²（§17.5 方法）加门控变体，
再在闭环里加步长补偿验证。

**架构可达 R²**（diag_attlin_arch.py / diag_firstorder.py，float64，目标 t_lin=Σδφ）：

| 权重函数 | τ=0.3 | τ=1 | τ=3 | τ=5 | τ=20 | τ=200 |
|---|---|---|---|---|---|---|
| softmax（凸组合，正） | 0.326 | 0.675 | 0.944 | 0.979 | **0.999** | **1.000** |
| **tanh 门控（带符号）** | 0.771 | 0.929 | 0.992 | 0.995 | **0.995** | **1.000** |
| **sigmoid 门控（带符号）** | 0.862 | 0.981 | 0.995 | 0.995 | **0.995** | — |
| 线性读出头（C3-v3） | — | — | — | — | — | **1.0000** |

**tanh/sigmoid 门控对半梯度的架构可达 R²≈0.995（τ≥3 全程），softmax 在高温也达
1.0（float64）**——三类带符号载体高温**殊途同归**于精确半梯度。机制：
`tanh(δ/τ)≈δ/τ` 是**带符号线性**（|δ|<τ 时），块中间输出 `M≈(1/τ)Σδφ`，V 放大 τ
即精确；softmax 一阶项同样给出 `Σ(δ_j−δ̄)φ_j`。**差异只在低温**：门控低温仍带符号
（0.77–0.86），softmax 低温退化成 winner-take-all（0.33）。门控没有"凸组合"的障碍
（权重 ∈(−1,1)，非正、非归一化），且**无均匀 O(1) 常数项**，高温数值稳（float32
不崩）；softmax 高温对精度敏感（§17.5）。

**闭环步长补偿**（diag_attlin.py，×τ/×2τ 抵消线性区 1/τ，4 seeds）：

- **补偿后 τ∈[1,50] 全温稳定 0.39–0.48**（tanh τ=5 0.42–0.45、τ=50 0.40–0.48；
  sig τ=5 0.42–0.44、τ=50 0.39–0.45），匹敌 qlearn（0.428–0.461）与 att_td_lin。
- **补偿前高温死、低温活** → 门控高温死**不是表达力**（R² 高），而是步长 1/τ 衰减
  被 `coeff=α/n` 没补偿 → 学不动。乘回 τ 后活。
- **唯一代价**：τ=0.1 饱和区补偿过度（0.20–0.34）。`tanh(δ/0.1)≈sign(δ)` 系数 ~1，
  无需 ×0.1——补偿公式假设线性区（|δ|<τ），饱和区应不乘。

**带符号载体光谱（统一 §17.4/17.5/17.6）**——改进算子能落的三类载体 + 一类死路：

1. **线性读出头**（C3-v3）：`Φᵀδ`，精确半梯度，R²=1.000，无温度敏感。显式、可证明。
2. **带符号门控**（tanh/sigmoid）：逐 token 饱和，R²≈0.995，需步长补偿，代价是
   幅度截断（饱和区）。绕过竞争归一化。
3. **score-scaled softmax**（att_td_lin）：`δ·softmax(δ/τ)`，高温隐式=半梯度
   （τ→∞ 精确，δ 前缀保持 O(1) 尺度），闭环 τ≥5 全程 0.43–0.48，**温和最优窗 τ≈5–20
   （τ=10 最优，§17.10 修正，详见 §17.4 表 + §17.10）**。带符号靠"乘回 δ"。
4. **纯凸组合**（diag_attimprove）：正归一化权重，结构性死（0.05）——exp 把 δ 的
   符号压成正概率质量，唯一"注定失败"的改进形式。

共同主线：**改进算子必须让系数带符号、保留 δ 的线性缩放**。softmax 家族里三条能
活的路（线性读出 / 带符号门控 / 乘回 δ）本质都是"绕过 exp 的符号瓶颈"；纯凸组合
是唯一不绕的，所以唯一死。

## 17.7 一阶引理：为什么高温活、低温死，三载体殊途同归（diag_firstorder.py）

**一阶展开（引理）**：对 `a_j = softmax(δ_j/τ)`，`τ→∞` 时

```
a_j = 1/n + (δ_j − δ̄)/(nτ) + O(1/τ²)，  δ̄ = (1/n)Σ_k δ_k
```

数值验证（随机 δ~N(0,1)，n=20）：一阶拟合相对误差 τ=3 时 0.069、τ=5 时 0.026、
τ=20 时 0.0016、τ=200 时 ~0——展开在 τ≥3 快速成立。

**推论 1（读出路线 A：高温精确但数值敏感）**。块输出 `Σ a_j φ_j` 的一阶项含
`(1/(nτ))Σ(δ_j−δ̄)φ_j`，而 `t_lin = Σδ_jφ_j = [Σ(δ_j−δ̄)φ_j] + δ̄·[Σφ_j]`——两项都在
读出头 span 内（后者被 bias 吸收），所以**读出精确可表达 Σδφ**，R² 随 τ 单调→1.0
（τ=20: 0.999，τ=200: 1.000，float64）。但均匀项 O(1) 压一阶项 O(1/τ)，SNR→0
（τ=200 时 0.005）→ **float32 下 ill-conditioned，误报成"崩"**（arch 原表伪影，
§17.5）。结论：**架构上高温读出=精确，数值上需要高精度/多样本**。

**推论 2（δ-gated 路线 B：att_td_lin 的机制，τ→∞ 精确且数值稳）**。

```
g^B = Σ_j δ_j·softmax(δ_j/τ)·φ_j
    = (1/n)Σδ_jφ_j + (1/(nτ))Σδ_j(δ_j−δ̄)φ_j + O(1/τ²)
```

**δ 前缀把 O(1/τ) 信号拉回 O(1)**：首项 `(1/n)Σδφ` 就是精确半梯度，无均匀淹没。
实测相对误差：τ=5 时 0.35、τ=20 时 0.085、τ=200 时 0.0085——**单调→0**。这就是
att_td_lin 在闭环里 τ≥5 全程 0.43–0.48、且 τ 越大越接近 qlearn 的原因（§17.4 表
τ=5/τ=50 均活，τ=0.1 死、τ=1 弱——与展开精度吻合：τ=1 时二次修正 O(1) 不可忽略）。

**推论 3（门控 = 同一线性区，用步长补偿掉 1/τ）**。`tanh(δ/τ)≈δ/τ`（|δ|<τ）也是
一阶线性，块输出 `M≈(1/τ)Σδφ` → 读出 ×τ 即精确（R²≈0.995）。高温"死"不是表达力
而是**步长 1/τ 衰减**：×τ 补偿后闭环 τ∈[1,50] 全温 0.39–0.48。门控无均匀 O(1) 项，
高温数值稳（float32 不崩），代价是低温饱和（tanh→sign）截断幅度。

**统一温度物理（精化 §17.4/17.6 的"竞争归一化吃掉符号"）**：

- **低温 τ→0（winner-take-all 凸组合）是唯一结构死区**：softmax 集中到单个 token，
  权重失去带符号线性缩放 → t_lin R² 仅 0.33、闭环死。这是"exp 压掉符号"的准确
  表述——**低温**的 exp 竞争归一化压掉符号。
- **高温 τ→∞（线性区）三载体殊途同归**：线性读出（恒精确）、δ-gated（自动 O(1)
  尺度）、门控（×τ 补偿）都精确退化为半梯度 Σδφ。softmax 的竞争归一化在高温**不再
  压符号**（分母 ~n·(1+O(1/τ))）。
- **不存在"高温结构死"**：arch 原表 softmax τ=20 "崩"是 float32 伪影；float64 下
  单调升到 R²=1.0。实际约束是**数值条件数**（读出路线高 τ 对精度敏感，float32
  需谨慎），不是结构。
- **精化（§17.11/17.12，当晚后半段）**：上两条"低温死区"指**随机特征（δ 无空间结构）**
  下带 δ 缩放的 score-scaled softmax 低温也死——那是**方差死**（one-hot 每步取最大 δ
  token，δ 无结构时方向漂移），**非结构死**。稀疏 + **平滑 × 几何对齐特征（RBF）** +
  确定性的 gridworld 下低温反而最优（one-hot 聚焦信号、过滤 TD 噪声，超半梯度）。
  **结构性必死的只有纯凸组合**（无 δ 缩放，exp 压符号）；"平滑 × 几何对齐"是低温从
  "方差陷阱"变"信号提取器"的开关（§17.12 对照 4/4b/5：光平滑不够、对齐被打乱则死）。

**对边界的影响**：改进算子层面三类带符号载体 + 一类死路的图景**不变且更干净**——
死路（纯凸组合）精确到"低温 winner-take-all"（结构死），带符号载体的低温死是
设定相关（稠密随机：方差死；稀疏确定：反而最优）。卡点依旧只剩评估值自包含
（§14/§18）。

## 17.8 结构化 MDP 泛化测试（diag_gridworld.py / diag_gridworld_probe.py）

**动机**：到此为止的所有证据都在"随机表格 MDP（nS=9, γ=0.5, 随机 Dirichlet 转移 + 均匀
奖励）+ 随机高斯特征（d=36）"上。审稿人必问：换结构化 MDP、换非随机特征还成立吗？
这里同时换两个变量：**确定性 6×6 网格世界（goal 吸收 +1 / pit 吸收 −1，步罚 −0.04，
γ=0.9）+ 空间 RBF 特征**（`φ(s,a)=ψ(s)⊗e_a`，ψ 为 3×3 高斯中心，d=K·nA=36，与随机
设定同维；36 状态压到 9 中心，线性逼近 Q* 是**真近似**）。40–60 个 MDP（随机 goal/pit 位置）。

**先失败（重要方法学教训）**：按原 `diag_attlin` 的**延续轨迹协议**（每次 rollout 从上次
终点继续，`s=S[n]`），所有机制死到 random 水平（qlearn −0.36 / random −0.34 / oracle 0.52）。
归因探针（diag_gridworld_probe.py）逐步拆：

- **不是特征问题**：RBF 线性天花板（lstsq 回归 Q* 的贪心回报）确实低（稀疏 0.06），但
  **one-hot 精确表达的 tabular qlearn 同样死**（−0.41 平坦）→ 特征表达不是（唯一）瓶颈；
- **不是注意力/改进算子问题**：标准逐转移 tabular Q-learning 跑 50 万步**也死**（−0.399
  平坦），VI 却拿到 oracle → 是 TD 学习动力学问题，与 softmax 无关；
- **根因 = on-policy 采样饿死起点分布**：插桩发现 50 万步里 **goal 访问次数 = 0**（行为
  被 Q≈0 时的固定 argmax 困在角落小环）；乐观初始化/高 eps 后 goal 访问近 30 万次，
  **但返回仍 −0.399**——因为**延续轨迹协议下起点状态（p0=角落）只采样一次**，行为一旦
  锁进 goal 盆地，corner 的 Q 永不再更新，而 MC 评估恰从 corner 出发 → 评估策略永远坏。
  随机 MDP 不踩坑的原因：p0=Dirichlet（处处高概率）、奖励处处稠密（每步都有新鲜信号，
  Q 立刻长成有结构形状、argmax 随状态变化 → 天然全局探索）、γ=0.5 短视界。

**修复 = episodic reset（每 rollout 从 p0 重新开始）**：这是网格世界的标准 episodic 协议。
修复后 tabular 稠密 qlearn 从 2.5 单调爬到 oracle 7.60（eps=0.3, 5000 步）。

**泛化主结果（episodic reset, eps=0.3, 2500 步, 40 MDP；seed 0 / seed 1）**：

```
稠密奖励（r=1−dist/8，梯度平滑，TD 可学）：
  oracle 7.37    random 3.22    RBF 线性天花板 5.08
  qlearn(线性读出头)  5.42 / 5.22      att_td_lin τ=5  5.20 / 5.11
  att_td_lin τ=50    5.11 / 5.38      tanh(×τ)         5.51 / 5.22
  att_td_lin τ=1（低温） 4.05 / 4.86  ← 明显落后，低温死区在结构化 MDP 上重现

稀疏奖励（原 gridworld, 只改协议）：
  oracle 0.53   random −0.31   lin-ceil 0.12
  qlearn 0.34   att_td_lin τ=1 0.38  τ=5 0.36  τ=50 0.29  tanh 0.31
  ← episodic reset 单独就把稀疏网格从 −0.36 救到 +0.29~0.38

稠密 + 随机特征（对照，隔离特征结构变量）：
  qlearn 6.20 但 w 发散（overflow 警告）；att_td_lin τ=50 5.81，τ=5 3.13，τ=1 1.93
  ← γ=0.9 大值尺度下随机特征数值不稳定，结构化特征更稳（本身是"特征结构→稳定性"证据）
```

**解读**：

1. **机制完整迁移到结构化 MDP + 非随机特征**。稠密 + RBF 下 qlearn/att_td_lin(τ≥5)/tanh
   全部收敛到 RBF 线性天花板（~5.0–5.5）附近，远超 random（~3.2）；离 oracle（~7.3）的
   差距由**特征表达上限**解释（lin-ceil 就是 5.0，9 中心 RBF 表达不了 Q*），不是机制缺陷。
2. **低温死区定性不变**：att_td_lin τ=1 在稠密 RBF 上明显落后（4.05 vs 5.2），与随机 MDP
   的 τ 图景一致；τ≥5 与 qlearn 重合（τ→∞ 精确退化为半梯度，§17.7 推论 2）。
3. **网格世界"失败"的真相是实验协议伪影**：延续轨迹（`s=S[n]`）→ 起点分布饿死 → 连
   tabular 都失败。这既是本文要写进 Methods 的注意点（**闭环评估必须 episodic reset 或
   保证起点状态被重采样**），也反过来提醒：随机 MDP 的成功部分是"易"的（稠密奖励掩盖了
   探索问题）。
4. **随机特征的数值不稳定性**（w 发散、overflow）是附加发现：半梯度 Q-learning 在 γ=0.9
   大值尺度下对特征结构敏感，结构化 RBF 特征提供稳定性。这支持"特征选择影响 ICRL 机制
   可行性"的论点。

**对边界的影响**：主结论（带符号载体可改进、低温纯凸组合是唯一死区、卡点只剩评估值
自包含）在结构化 MDP + 非随机特征下**原样成立**；新增边界条件——**机制需要 episodic
采样保证起点覆盖**，否则改进算子的输入（TD 误差）本身就缺乏信号，任何 TD 学习都失败。

## 17.9 真实单层 softmax 块在结构化 MDP 上学改进算子（train/evaluate_c3_v3_gridworld.py）

**动机**：§17.8 的机制迁移全部是 numpy 模拟（读出头/门控是手写的线性代数）。这里用**真实
单层 softmax 块**（SoftmaxEvalImproveV2，§11/§17 的架构：输入上下文 Z → 单层 softmax
注意力 → 评估读出 v + 改进读出 dw）在网格世界上做最后的真实验证——模型能否学会 teacher
（numpy qlearn 读出头 `dw=(α/n)Φᵀδ`）的改进算子。这正是 C3-v3 结论在结构化设定下的完整复刻。

**协议**：与 train_c3_v3_gridworld.py 一致——每 MDP 随机 goal/pit（不重叠、不在起点）、
RBF 特征（K=9, σ=1.6, d=36）、episodic reset、稠密奖励、eps=0.3、α=0.2、n=20；K=400 个
MDP × T=30 步，loss = ½·MSE(dw_pred, dw_tgt) + lam_eval·½·MSE(v_pred, v_tgt)。训练 loss
收敛到 0.000000（模型精确拟合了 qlearn 读出头的改进方向）。闭环评估：60 个新 MDP，2500
更新步，每 250 步 MC 评估一次。

**结果（60 MDP, dense, 跨 3 seed）**：

```
seed  model(外部活 φ·w)  teacher  model-self(自包含)  oracle  random
 0       3.94→5.01       4.54→5.51     2.51→2.40       7.36    3.15
 1       4.65→5.31       5.08→5.16     2.67→2.75       7.27    3.21
 2       4.61→5.61       4.24→5.12     2.73→2.47       7.19    3.06
 mean    ~5.31           ~5.26         ~2.54           ~7.27   ~3.14
                        （RBF 线性天花板 ~5.08）
```

**解读**：

1. **真实单层 softmax 块在结构化 MDP 上学到了改进算子**：外部锚定下模型闭环跨 3 seed 均值
   ~5.31 ≈ teacher ~5.26 ≈ RBF 线性天花板 5.08，远超 random ~3.14（seed 0 单次 5.01 vs 5.51
   的差距是偶然，跨 seed 看两者重合）。与随机 MDP 的 C3-v3 结果（0.43 ≈ teacher 0.44）完全
   对应——机制迁移跨设定成立，不止是 numpy 手写线代才行的巧合。
2. **self-eval=1（模型自己维护 v_state 做评估，不喂活 φ·w）同样崩（跨 3 seed 稳健）**：三个
   seed 全部不改善（2.40 / 2.75 / 2.47，均值 ~2.54），且全部**低于 random**（3.06–3.21）。
   与随机 MDP 的自包含崩（0.15 vs 外部锚定 0.43）同构——**「评估值自包含」是跨设定的普适
   障碍**。机制上很清楚：自维护的 v_state 初始全零 → 上下文里没有活 φ·w → 模型产出的 δ
   基准（M 和 cur）全错 → 改进方向无信息量 → 每次更新在噪声上漂移，最终劣于 random。
3. 这补上了整个证据链的最后一环：**能闭环的两条路（C3-v3 线性读出、att_td_lin 权重内
   score-scaled softmax）在结构化 MDP 上仍成立；卡点仍是且仅是「改进需要活的 φ·w，单层
   softmax 块自给不了」**。边界图景（§19）在结构化设定下原样收尾。

## 17.10 低温→高温相变扫描：τ 连续刻画临界温度（diag_gridworld_tauscan.py）

这里在稠密 gridworld 上扫 13 个 τ（0.1–50，对数分布），40 MDP × 2500 步，eps=0.3，seed 0。

**结果**：

```
                     final    best
```

2. **谷底在 τ≈0.5 而非 τ→0**：τ=0.1 反而比 τ=0.5 略好。解释：τ→0 时 softmax≈one-hot 取

   最不利。这是小的二阶效应，主图景（低温死 / 高温活）不受影响。
3. **有限 τ 的轻微正则化增益**：τ=10 达到 5.49，**超过**纯半梯度 qlearn 5.42。二阶项
   `(1/nτ)Σδ_j(δ_j−δ̄)φ_j` 按 TD 误差大小加权特征方向，等价于给大误差样本更高权重，在

   qlearn 0.4397）——**两个设定下都存在温和最优窗 τ≈5–20，修正了 §17.4 "随 τ 单调改善、
   无最优窗"的说法**（旧说法只在 τ≤10 的采样下成立，τ=50 已回落）。
4. **与一阶引理（§17.7）定量一致**：稠密奖励 r∈[0.125,1]、γ=0.9 下 δ 量级 ~O(1)，
   一阶线性化 `softmax(δ/τ)=1/n+(δ−δ̄)/(nτ)+O(1/τ²)` 成立需 τ≫|δ|≈1——实测正是
   τ≥5 起进入线性区、τ≥10 饱和。温度物理从"代数极限"变成"可观测的相变标度律"。

## 17.11 稀疏奖励：低温反而最优 —— 稀疏度效应（tauscan 对照；平滑×对齐是开关，见 §17.12）

**动机**：§17.10 的相变曲线只在稠密奖励下。稀疏奖励（§17.8 原网格世界）下 δ 信号结构
完全不同（大部分步 δ=γV(s′)−V(s) 是 TD 同质噪声，只有近 goal 转移 δ 有强信号）。扫同一
τ 列表看相变是否翻转。

**结果（稀疏，其余参数与 §17.10 相同）**：

```
                final    best
  qlearn        0.3365   —
  att_td_lin τ=0.1  -0.2237  -0.2054   ← 低温死（极低）
              τ=0.3  -0.2630  -0.0868
              τ=0.5   0.0086   0.0750
              τ=0.7   0.2988   0.3546
              τ=1     0.4204   0.4375   ← 已超 qlearn
              τ=1.5   0.4241   0.4241
              τ=2     0.4578   0.4578   ← 峰值，+36% 超 qlearn
              τ=3     0.3780   0.3859
              τ=5     0.3631   0.3631
              τ=10    0.3613   0.3613
              τ=20    0.3137   0.3300
              τ=50    0.2877   0.2877   ← 高温回落
  oracle 0.529   random −0.312   lin-ceil 0.117
```

**与稠密对照（§17.10）**：稠密最优 τ≈10（高温端）、稀疏最优 τ≈2（低温端）；稀疏下
τ∈[1,2] 的增益还大得多（0.42–0.46 vs qlearn 0.34），而稠密 τ=10 只是 5.49 vs 5.42
的微小增益。**温度最优值随奖励稀疏度翻转**。

**解读**：

1. **温度 = TD 信号稀疏度的匹配滤波器（注意：§17.12 对照证明稀疏度单独不够，"平滑
   × 几何对齐"特征才是决定性开关，这里先看效应本身）**：稀疏奖励下 δ 信号集中在少数转移（近
   goal），大部分步 δ 是噪声。低温 softmax≈one-hot 每步只取最大 δ 的 token——确定性
   网格世界下最大 δ token **稳定指向 goal 方向** → 低温把学习自动聚焦在信号最强的转移、
   过滤噪声 → 又高效又稳。高温均匀平均把稀疏信号稀释掉（大部分权重落在无信号的噪声步）
   → 差。稠密奖励下 δ 处处有结构，均匀平均最大化样本效率 → 高温最优。
2. **修正"低温死区"表述**：随机 MDP（§17.4 τ=0.1/1 → 0.018/−0.010）和稠密 gridworld
   的"低温死"是**低温 + 稠密信号 + 随机转移**的特定现象（one-hot 每步只更新少数 token，
   且最大 δ token 随随机转移漂移 → 高方差、方向不一致）。稀疏确定性 gridworld 下低温是
   **特征提取器**，τ=1 就活。真正结构性必死的仍只有**无 δ 缩放的纯凸组合**（§17.4，
   exp 把符号压成概率质量）。§19 结论 2 需加限定词（见 §19）。
3. **统一三设定图景**：随机 MDP（稠密+随机转移）→ 最优 τ≈10；稠密 gridworld（稠密+确定性）
   → 最优 τ≈10；稀疏 gridworld（稀疏+确定性）→ 最优 τ≈2。温度的物理角色从"代数极限
   （τ→∞=半梯度）"升级为"**信号-噪声匹配旋钮**"：δ 越稀疏 / 转移越确定性，最优 τ 越低
   （one-hot 提取）；δ 越稠密 / 转移越随机，最优 τ 越高（均匀平均）。
4. 对论文的影响：att_td_lin 的 τ 是**可调超参而非必须拉满**——稀疏奖励场景下低 τ（~1–2）
   反而该选；这与"低温纯凸组合死"的旧结论正交。§17.4/§17.10 的"最优窗 τ≈5–20"只在
   稠密设定成立。

## 17.12 低温复活的三因素归因：平滑 × 几何对齐是决定性的（diag_randmsparse.py + diag_randgoal.py + diag_randfeat.py + diag_gridworld_featalign.py）

**动机**：§17.11 的 gridworld 同时变了稀疏度、转移确定性、特征结构。逐步拆变量，定位
"低温 one-hot 提取信号"到底需要什么。三个对照实验链（随机 MDP nS=9/nA=4/γ=0.5/随机特征，
与 §17.4 同构）：


**特征结构是决定性的**：同一定性 gridworld、同一稀疏奖励，RBF 下 τ=1 活、随机特征下

**对照 4b（补，diag_randfeat.py）：同随机 MDP，只换"人工平滑特征"——平滑本身不够**

随机 MDP（nS=9，D 模式=goal+pit+确定性+吸收，γ=0.9，40 MDP，1500 步）上人为构造
**一维位置编码 RBF 特征**（pos[s]=s 线性排列，5 中心，σ=1.2；d=20；"平滑"但位置与
转移结构无关），与同 MDP 随机特征对照：

```

random（随机特征）:    qlearn 0.491  τ=1 0.316 | τ=2 0.486 | τ=5 0.531 | τ=10 0.458
```
人工 RBF **不复活低温**（τ=1 0.293 < qlearn 0.384），且 RBF-pos 的 qlearn（0.384）反而
**低于** random 特征 qlearn（0.491）——随机 MDP 的状态编号 s 与转移结构无关，把 9 态压
缩成 5 中心的光滑函数丢失了任意表达能力。**"平滑但不对齐"的特征一无是处**。

**对照 5（决定性，diag_gridworld_featalign.py）：同 gridworld，只破坏几何对齐**

gridworld 上把 RBF 的位置映射**随机打乱**（perm[s] 反解成假 2D 坐标再做 RBF）：特征
仍平滑（相邻假位置的状态特征相近），但"特征距离=转移距离"的对齐被破坏。稀疏 gridworld，
γ=0.9，40 MDP，2500 步，3 seeds：

```
         qlearn              τ=1                  τ=2        τ=5        τ=10
aligned  0.321/0.380/0.458   0.372/0.462/0.480    0.28-0.44  0.27-0.44  0.20-0.39
permuted 0.029/0.078/0.234   0.015/0.145/0.149    0.07-0.15  ...
random   0.224/0.274/0.447   −0.399/−0.399/−0.399  −0.26     0.20-0.27  0.19-0.31
```
**aligned 的 τ=1 每 seed 都超 qlearn**（0.372>0.321、0.462>0.380、0.480>0.458）——低温
复活复现；**permuted 的 τ=1 转死**（0.02–0.15），且连 qlearn 表达天花板都崩（0.03–0.23
vs 对齐版 0.32–0.46）——**几何对齐同时是 RBF 表达能力与低温聚焦信号的来源**；random
的 τ=1 跨 3 seed 崩到 random 之下（−0.40）。对照 5 把"特征结构"从 gridworld 的相关性
升级为同 MDP 同特征族的因果性。

**解读**：

1. **低温 one-hot 复活 = 平滑特征 × 几何对齐**（对照 4b/5 把"平滑"进一步精化）：
   - **平滑（必要不充分）**：RBF 使 Q(s,a)=ψ(s)·w 空间平滑 → δ 有空间结构 → 最大 δ
     token 能稳定指向 goal 前一步。随机特征下 δ 无结构，one-hot 每步选的方向漂移 →
     高方差死（对照 4）。
   - **几何对齐（决定性，新增）**：光平滑不够（对照 4b 阴性）——若特征的位置/距离与
     转移图无关，δ 在特征空间没有与 MDP 结构对齐的聚焦区。gridworld 的 RBF 活是因为
     **网格坐标 = 转移邻接**（上下左右=坐标±1）；把位置映射打乱（对照 5）后 τ=1 从活
     转死，且连 qlearn 表达天花板都崩——**对齐同时是表达与聚焦的来源**。
   - **确定性转移 / 信号稀疏**：辅助变量——稳定最大 δ 方向 / 决定提取收益大小
     （对照 2/3，单独都不够）。
2. **为什么随机 MDP 怎么改都不行**：不只是"随机特征无结构"（对照 1–3），而是**任何
   特征，只要其几何不对齐转移图，就没有可聚焦的空间结构**——人工平滑 RBF 也不行
   （对照 4b）。随机 MDP 上状态编号与转移无关，天然无法构造"对齐"特征；这是随机 MDP
   与 gridworld 的本质差别，与稀疏度、确定性、goal 结构无关。
3. **修正 §17.11 图景（四象限 → 加"对齐"维）**：
   - 平滑 + 对齐 + 稀疏 + 确定性：最优 τ≈1–2，**低温活且超半梯度**（§17.11 + 对照 5
     aligned：τ=1 0.37–0.48 > qlearn 0.32–0.46）；
   - 平滑 + 对齐 + 稠密：最优 τ≈10，低温死区 τ_c≈3（§17.10）；
   - 平滑但**不对齐**（permuted / 随机 MDP 人工 RBF）：低温死 + 表达天花板也崩
     （对照 4b/5）；
   - 随机特征：低温死（随机 MDP frac 全谱、gridworld random）。
   低温 one-hot 从"方差陷阱"变"信号提取器"的开关 = **平滑 × 几何对齐**；稀疏度决定
   提取收益，确定性决定方向稳定性。
4. 对论文：att_td_lin 低温 τ 只在**几何与任务转移对齐的空间平滑特征**（卷积视觉特征、
   RBF 位置编码、邻接图嵌入）上可用；纯随机嵌入选高温；**几何未对齐的"平滑"特征无
   价值**（表达与聚焦同时失效）。这是可操作的设计准则。

**机制直接观测（diag_gridworld_deltaprobe.py + diag_gridworld_deltaevolve.py）**：

上面的"聚焦信号"是从闭环 return 推断的，下面直接观测训练中的 δ 场（稀疏 gridworld，
γ=0.9，aligned RBF vs 随机特征，15 随机实例 × 3 seed）：

- **稳态 δ 场空间平滑度**：相邻网格状态 max δ 之差的均值（÷全局 std）——aligned RBF
  显著更小（0.64–0.69 vs permuted 1.02–1.10 / random 0.92–1.06，跨 3 seed 稳定）。
  对齐 RBF 让 δ 场空间平滑 → one-hot 每步选中的 token 在空间上连续而非随机跳变，
  这是低温聚焦方向稳定的前提。
- **训练早期 δ 强聚焦近 goal（δ-距离 Spearman）**：aligned RBF 下 att_td_lin τ=1 在
  step 50–250 的 rho ≈ +0.75~+0.79（Q≈0 时 δ≈r，进 goal 的转移 δ=1 最大 → δ 高度集中
  在近 goal 区），收敛后漂移（rho→+0.09~+0.27，δ 变成表达残差）；**随机特征下 rho 全程
  为负（−0.15~−0.55）**——one-hot 聚焦方向与 goal 相反，学习信号被误导 → 闭环 τ=1 跌
  到 random 之下。
- **机制表述修正（比 §17.12 最初更准确）**：不是"argmax δ 稳定指向 goal 前一步"（稳态
  不成立），而是"**训练早期 δ 由奖励主导、强聚焦近 goal 区，且场空间平滑** → one-hot
  把学习信号持续推到信号区（过滤 TD 噪声）；随机特征下聚焦反向/粗糙 → 方向漂移方差
  死"。几何对齐同时保证早期聚焦（Q 平滑可学）与稳态平滑（δ 场连续）。

## 17.13 真实模型权重内改进边界：读出 vs 权重内凸组合（train/evaluate_c3_v3_gridworld.py --variant）

补完真实单层 softmax 块构造性证明的最后一块：**改进的 δ 线性缩放必须在块外读出；
层自身 attention 权重只能给凸组合（闭环不可靠）**。三方对照（同设定：稠密 gridworld，
RBF 特征 d=36，60 MDP，2500 步，seed 0，外部锚定活 φ·w）：

| 变体 | 读出形式 | 闭环 return | 结论 |
|------|---------|------------|------|
| V2 | 块外线性 (α/n)Φᵀδ（半梯度） | 5.01（3 seed 5.01–5.61） | 活（§17.9） |
| V5 | 块外 score-scaled Σδ·softmax(δ/τ)·φ，τ=10 | 4.89–5.22 | 活，接近天花板 5.2–5.5 |
| V4 | 权重内凸组合 α·Φ·a（a=层自身 attention 权重，无 δ 缩放） | **2.50（start=final，零学习）** | **死，< random 3.15** |
| V4b | 凸组合 + 可学全局缩放 | **2.50（同 V4）** | readout_scale 学到 1.0（没用上）→ 非量级问题 |

**V4 的"拟合 vs 闭环"分裂（关键机制）**：
1. **训练 loss→0（~1e-5）**：凸组合能**拟合** qlearn 目标——过参数化特征（d=36 > n=20）
   使特征矩阵 Φ 有 ≥16 维 null 空间，模型把 attention 权重 a 学成 Φ·a ≈ (α/n)Φ·δ 的解
   （a = αδ/n + null(Φ) 补偿），在训练分布上精确模仿带符号目标。
2. **但闭环完全失败（2.50 钉死，start=final）**：闭环里 w 从随机初始、由模型自己的 dw
   演化，δ 分布与训练时 teacher 提供好 w 的路径不同 → 学到的 a 编码失效 → w 漂移 → Q=φw
   崩。**拟合（表达）≠ 可靠闭环（自举路径泛化）**。
3. **V4b 的 readout_scale 学到 1.0**（模型不用全局缩放，靠 null 空间压量级）→ 排除
   "整体量级缺失"归因；死因是**逐 token δ 符号/缩放**在层自身权重里不可表达 + 拟合
   不泛化到自举路径。
4. **结论**：score-scaled 算子（§17.4）的"δ 前乘"必须由块外读出（V5/numpy）提供；层自身
   softmax 权重只能给凸组合（无 δ 前乘），闭环不可靠。与 §17.6 主线完全一致：**系数必须
   带符号、保留 δ 线性缩放**。真实模型构造性边界 = 改进要 δ 线性缩放，而它只能落在块外
   （线性读出 / score-scaled 读出），无法落进层自身权重。

## 18. diag_v5：自包含 memory 的穷举 —— 所有自更新设计都死

### 18.1 动机

C3-v3 自包含（self-eval=1）崩的根因是 **memory 线不会跟随 w**（copy 需要输入就有
`φ·w`）。V5 想法：让 memory 线自己**做值迭代**更新——`v ← v + α(r+γM−v)` 是
r/M/v 三行的线性组合，softmax 的 memory 行更新**精确可表达**（无 bilinear），
改进读出用同一个 δ。这样 v_state 自包含地收敛到 Q*。

- **v5a（解耦 VI）**：`δ = r+γM−v_state`，`w += (α/n)Φᵀδ`（v 和 w 都用 memory 值，
  完全自包含、无 bilinear）；
- **v5b（VI 只供 M）**：M 用 VI 跟踪的 v_state 的 max，`w` 更新用标准 Q-learning
  `δ = r+γM−φ·w`（需 bilinear，模型不可表达，当上界参考）。

### 18.2 结果（numpy，60 MDP，400 帧，4 seeds；oracle 0.53±0.01）

| 机制 | v_state 初始 0 | v_state 初始 φ·w |
|---|---|---|
| **v5a（解耦 VI）** | **0.03–0.05** | **0.00–0.04** |
| **v5b（VI 供 M + Q-learning）** | **0.40–0.45** | **0.43–0.45** |

（seed0 明细：v5a 0.0513/−0.0125；v5b 0.4031/0.4192。4 seeds 范围见上表，
v5a 一致贴随机、v5b 一致 0.40+。）

### 18.3 解读

- **v5a 死（actor 饿死）**：值迭代独立于 w 收敛到 Q*，`δ = r+γM−v → 0` 时 w 还停在
  随机初始附近——改进步在 w 学到好策略**之前**就消失。VI 的价值线与 w 解耦，
  是它的死结。经典 actor-critic 的批评器收敛到 `Q^π`（依赖策略）才不会饿死，
  而"max 值迭代"收敛到 `Q*`（与策略无关），恰好饿死 actor。
- **v5b 活（0.40–0.42）但非自包含**：w 更新需要 `φ·w`（bilinear），模型不可表达。
  它精确解释了 C3-v3 self0 为什么能活——**能工作的机制无一例外要求当前值项是活的
  `φ·w`，而 `φ·w` 正是 softmax 块无法自给的部分。**

## 19. 最终边界图景：softmax attention 里的 policy improvement

现在有 6 个方向的证据，边界完全闭合：

| 设计 | 实现 | 闭环 | 卡点 |
|---|---|---|---|
| C3（on-policy 评估+读出） | 模型 | 0.25 死锁 | E[δ]=0（Bellman，§3） |
| C3-v2（滞后 memory max） | 模型 | 0.005–0.07 | v_state 追不上 φ·w（§5） |
| C3-v3 self1（copy memory） | 模型 | 0.14 | copy 无法跟随 w（§13） |
| C3-v4 self1（重推导 φ·w） | 模型 | 0.17 | bilinear 残差 R²≈0.92（§14） |
| **diag_attimprove**（TD 进 score 纯凸组合） | numpy | 0.05 | 纯凸组合无带符号线性 δ（§17） |
| **v5a**（VI memory 解耦） | numpy | 0.05 | actor 饿死（§18） |
| **C3-v3 self0**（外部 φ·w 锚定） | **模型** | **0.42–0.45** | **工作，φ·w 来自外部** |
| **v5b**（VI 供 M + Q-learning） | **numpy** | **0.40–0.42** | **工作，需 bilinear φ·w** |
| **att_td_lin**（δ·softmax(δ/τ)·φ，τ→∞=半梯度） | **numpy** | **0.43–0.48** | **工作，τ≥5 匹配/超 qlearn（§17.4）** |
| **att_td_tanh / att_td_sig**（带符号门控 + 步长补偿） | **numpy** | **0.39–0.48** | **工作，R²≈0.995，τ∈[1,50] 全温（§17.6）** |
| **V5**（真实块外 score-scaled Σδ·softmax(δ/τ)·φ，τ=10） | **模型** | **4.89–5.22** | **工作，δ 前乘在块外读出（§17.13）** |
| **V4 / V4b**（真实权重内凸组合读出，无 δ 缩放） | **模型** | **2.50 / 2.50** | **死（拟合 loss→0 但不泛化到闭环自举路径；V4b 可学缩放学到 1.0 非量级问题，§17.13）** |

### 结论（精确且诚实）

1. **能做的部分**：softmax attention 能做 policy improvement 的"贪心化"——
   max bootstrap（低温 softmax 代理 max，§11）+ 线性改进读出 `Φᵀδ`（§12），
   闭环 **0.42–0.45**，匹配 numpy Q-learning，超过单步贪心（0.376）。
   **这是单层 softmax 块里第一次可证明的 Q-learning 式 policy improvement。**
   （文献复核 2026-08-11：04 论文 Xie & Liu 2605.07333 是 softmax 但**只做评估**；
   03 论文 Liang & Lai 2605.05755 做改进但用**线性** attention（无 softmax 归一化），
   实现的是 **semi-gradient SARSA / actor-critic**——正是我们"改进=半梯度 Σδφ"的
   线性读出头版本（C3-v3 同机制），证明"线性 attention 能做改进"；S-ICQL（ICLR
   2026，arXiv 2506.01299）是多 head transformer + expectile 回归 + AWR 的工程路线，
   无单层构造证明；"In-Context Learning as Implicit Policy Gradient"（2607.23153）
   是 REINFORCE 式 reward-weighted aggregation，机制不同。**单层 softmax + 线性
   读出/半梯度式改进 + 边界分析，仍无人做过。**）
2. **改进算子层面 softmax 完全能做，三类带符号载体**（§17.4/17.6）：
   - `δ·softmax(δ/τ)`（att_td_lin）：τ→∞ **精确退化为半梯度 `(1/n)Σδφ`**，
     τ≥5 达 0.43–0.48（匹配/超过 qlearn 0.428–0.461）；
   - **带符号门控**（tanh/sigmoid）：架构 R²≈0.995，步长补偿后 τ∈[1,50] 全温
     0.39–0.48；
   - **线性读出头**（C3-v3）：精确 R²=1.000。
   根因精确落在 **低温竞争归一化（winner-take-all）+ 不带线性缩放**：低温时 exp 的
   分母挤掉 δ 的符号/缩放信息，会死；高温时 softmax 一阶线性化保留符号（§17.7），
   带符号载体（门控 / 乘回 δ / 线性读出）都是半梯度。
   **"softmax 做不了改进"是错的——正确说法是"低温纯凸组合（无线性缩放）做不了"。**
   限定词（§17.11/17.12）：带 δ 缩放的 score-scaled softmax 的"低温死区"只在**随机特征
   （δ 无空间结构）**设定成立（one-hot 高方差）；**稀疏 + 平滑 × 几何对齐特征（RBF）+
   确定性的 gridworld 下低温 τ≈1–2 反而是最优**（one-hot 聚焦信号、过滤 TD 噪声，超半
   梯度 qlearn 36%）。因果验证（§17.12）：随机 MDP 上奖励稀疏化 / 确定性化 / goal 结构
   三连对照 τ=1 都不复活；**决定性实验有两个——(a) gridworld 同设定只换特征（RBF 下
   τ=1 活、随机特征下 τ=1 死 −0.38）；(b) 随机 MDP 上人工平滑 RBF 不复活（平滑但不对
   齐）+ gridworld 位置映射打乱 τ=1 转死（3 seed）→ 低温复活的关键开关是"平滑 × 几何
   对齐"，确定性/稀疏度只是辅助**。温度不是越高越好。
   **真实模型边界（§17.13）**：score-scaled 的 δ 前乘必须落在**块外读出**（V5 τ=10 活
   4.89–5.22）；层自身 attention 权重的凸组合读出即使训练拟合 loss→0 也**闭环死**
   （V4/V4b 2.50 < random 3.15，可学缩放学到 1.0 排除量级归因）——**改进的 δ 线性缩放
   无法落进层自身权重，只能由块外读出（线性 / score-scaled）提供**。
3. **做不到的部分收窄到唯一一项**：**评估值的自包含**。改进算子（att_td_lin 或
   线性读出头）需要活的当前值 `φ·w`，而单层 softmax 块无法自给这个值（copy 漂移 /
   重推导 bilinear 障碍 R²≈0.92 / 值迭代 actor 饿死）。所有能闭环的机制无一例外
   要求"当前值项是活的 `φ·w` 且外部进块"。03 论文用线性（未归一化）attention 做
   semi-gradient SARSA/actor-critic，正是能精确表达未归一化收缩项（`Φᵀδ`/`ΦᵀΦw`）
   的版本（机制解读，§10）；softmax 用"外部值项 + 改进读出"能达到同样水平
   （0.42–0.48）却留着自包含缺口。

### 结构化设定复核（§17.8/17.9，跨设定不变式）

上面的边界图景建立在随机表格 MDP + 随机特征上。§17.8/§17.9 在**确定性 6×6 网格世界
+ 空间 RBF 特征**（γ=0.9）上复核后，边界图景**逐条不变**：

- **改进算子的三类带符号载体全部迁移**：qlearn / att_td_lin(τ≥5) / tanh 在稠密奖励下
  全收敛到 RBF 线性天花板（~5.0–5.5），远超 random（~3.2）；**低温死区跨设定重现**
  （τ=1 落后）——但只限于稠密信号 + RBF 特征：稀疏 + RBF 确定性 gridworld 下低温 τ≈1–2
  反而最优；同设定换随机特征则低温死；RBF 位置映射打乱后低温转死且表达天花板崩
  （§17.11/17.12，平滑 × 几何对齐是开关）。
- **真实单层 softmax 块学到改进算子**（§17.9，跨 3 seed）：外部活 φ·w 锚定下模型闭环
  ~5.31 ≈ teacher ~5.26 ≈ 天花板 5.08——随机 MDP 的 C3-v3 结论在结构化设定下原样成立。
- **"评估值自包含"是普适障碍**（§17.9）：self-eval=1（模型自维护 v_state）在网格世界上
  **跨 3 seed 全部不改善且劣于 random**（2.40–2.75 vs random 3.06–3.21），与随机 MDP
  的 0.15 vs 0.43 同构。唯一卡点在两种设定下是同一个。
- **新增边界条件（方法学）**：闭环评估必须 episodic reset（每 rollout 从 p0 重开），
  否则起点分布饿死，连 tabular Q-learning 都失败——这是与 softmax 无关的 TD 学习协议
  要求（§17.8）。

### 下一步（重构后）

1. **主结果（推荐）**：**一类机制（半梯度 Σδφ）× 三类带符号载体**（§17.6 光谱）——
   - **C3-v3**：softmax 评估（memory 精炼）+ **线性读出头** `Φᵀδ` + 外部值项
     （0.42–0.45）。显式、精确（R²=1），论文首选。
   - **att_td_lin**：改进靠 **attention 权重的高温一阶项**（`δ·softmax(δ/τ)`，
     τ→∞ 精确=半梯度）。τ 依信号/特征选：稠密随机特征下 τ≈5–20（0.43–0.48，§17.10
     τ_c≈3–5、τ≈10 略超半梯度）；稀疏 + 几何对齐的平滑特征（RBF）下 τ≈1–2 反而最优
     （§17.11/17.12，τ=1 跨 3 seed 超 qlearn）；**未对齐的"平滑"特征低温无价值且表达
     天花板也崩**（§17.12 对照 4b/5）。
   - **门控**（tanh/sigmoid）：带符号、无竞争归一化，架构 R²≈0.995，步长补偿后
     全温 0.39–0.48。
   三者共用同一机制：改进的本质是半梯度 `Σδφ`（带符号、线性缩放）；低温纯凸组合
   死。改进需要活的 `φ·w` 当前值，值自包含（§14/§18）是唯一卡点。
2. **V5 架构（若要"全自包含"）**：接受"值项 = 残差/embedding"——`φ·w` 由环境
   提供进块，模型只学改进。这本来就是 transformer 的定位（输入给 embedding，
   不自己造 embedding），把"自包含"重新定义为"值进上下文"而非"块内重算"。
3. **放弃的方向（记录在案）**：单块内自给 `φ·w`（bilinear 障碍，R²≈0.92 是结构
   地板）；TD 进 score 的**纯凸组合**算子 `Σ softmax(δ/τ)φ`（无线性缩放，0.05）；
   VI memory 解耦（actor 饿死）。这些都已用 numpy/模型实验钉死，不必再试。
