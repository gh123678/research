## Research question

Can the approved governance design be translated into a single canonical repository policy, a reliable Claude entry point, reusable task templates, and a current-workspace pointer without changing research code or active scientific conclusions?

## Falsifiable hypotheses

1. A canonical `AGENTS.md` plus a short `CLAUDE.md` entry point can give GPT and Claude one non-duplicated source of authority.
2. A structured task template can make initiation, objection, handoff, evidence, and dual verification auditable.
3. The governance change can preserve the active scientific objective and avoid modifying code, results, or manuscript content.

The task fails if the final rule files contain contradictory authority, allow Claude to redefine a task, omit the user objection gate, or modify files outside the declared scope.
