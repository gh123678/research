## 研究问题

不给转移核，只用**认证批里本来就有的**后继观测，能不能把那 `28` 个百分点的大部分拿回来？

## 构造（L12M）

`Q̂ − Q^π = −(I−γP^π)^{-1}ρ` 是恒等式。`L123` 用它但需要 `P`。**同一批认证数据里，每对 `x=(s,a)` 的样本本来就带了 `s' ~ P(·|s,a)` 的 iid 观测**，所以 `E_{s'~P(·|s,a)}[f(s')]` 对任意 `f` 都可以无模型地估出来。归纳：

```text
W_0        = max_x ε_x/(1−γ)                       （|w| 的有效上界）
W_{k+1}(s) = Σ_a π(a|s) ε(s,a) + γ Σ_a π(a|s) [ T_x(W_k) + c_k(x) ]
T_x(f)     = (1/n_x) Σ_i f(s'_i)                   （该对观测到的后继直方图）
c_k(x)     = ‖W_k‖∞ · sqrt(log(1/δ_k)/(2 n_x))     （单侧 Hoeffding）
```

`|w| ≤ W_k` 对每个 `k` 成立（归纳：`|w(s)| ≤ ε̄(s) + γ Σ_a π(a|s) E[|w(s')|]`），最后一次代入给出 `|u|` 的上界。收敛到 `(I−γT̂)^{-1}ε̄ ≈ (I−γK)^{-1}ε̄`，即 `L123` 的极限，但每一步都要为自己的估计付置信项。

**风险**：`δ_step` 对半分成 `δ_eps`（逐对 MP，双侧，`δ′ = δ_step/(2d)`，共花 `δ_step/2`）与 `δ_prop`（传播估计，`δ_step/2`）；后者再分成 `n_iter·d` 份（每个迭代每对）与 `d` 份（最后一次）。样本跨迭代复用，故风险对 `n_iter` 做 union，而非假设每次独立。**不读任何核。**

## 可证伪假设（登记于运行前）

与 FP-BOUND-001 **完全相同的环境、种子与批次计划**（`task_index 12..23` × 两种 mixing，`c16k` 与 `c64k`），只多一个臂。因此四个共享臂必须逐位复现 FP-BOUND-001 的封存包——这本身是一条核对，使新臂的比较对象是被交叉验证过的臂。

- **H1（强制）**：`L12M` 在每条记录上覆盖实测 `‖Q̂−Q^π‖∞`（0 违规）；且 `L12M ≤ L12` 在**每条**记录上成立（估计版不可能优于同预算的界之外）。任一不成立即 FAIL。
- **H2（量级）**：`L12M` 相对 `frozen` 的降幅落在 **`[−45%, −15%]`**。
- **H3（回收率）**：`L12M` 至少收回 `L123` 相对 `L12` 收益的 **70%**，即 `(mean_L12 − mean_L12M)/(mean_L12 − mean_L123) ≥ 0.70`。
- **H4（与核版的关系）**：`L123 ≤ L12M` 在至少 **90%** 的记录上成立（核版应当至少一样紧）。
- **H5（判决后果）**：`c64k` 下 `L12M` 的发出数比 `L12` 至少多 `3` 条。
- **H6（风险账务）**：`δ_eps + δ_prop = δ_step` 精确；`δ_eps` 的实花等于 `d·δ′`。
- **H7（交叉核对）**：四个共享臂（`frozen`/`L1`/`L12`/`L123`）的 `e_q`、判决与发出与 FP-BOUND-001 的封存包**逐位一致**。
