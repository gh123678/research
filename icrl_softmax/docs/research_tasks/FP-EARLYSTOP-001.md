## 研究问题

在**未用于任何前期探索的新环境**上，同预算比较三条路线处理"全状态合取门槛导致整条轨迹早停"的能力：

- **A 基线**：合取门槛（`min_s LB_s > 0`），MP 证书，每步每对 `n = 16,384`；
- **B 加数据**：同 A，每步每对 `n = 65,536`（4 倍数据）；
- **C 按状态保守更新**：每步每对 `n = 16,384`（同 A 预算），逐状态首通：对每个状态独立在下降 η 网格中取首个 `LB_s > 0` 的倾斜；`LB_s ≤ 0` 的状态保持不动。

## 预登记（运行前冻结）

- **新环境**：同一 MDP 族（4 状态 3 动作、`GAP_BONUS=0.5`、mixing ∈ {0.08, 0.5}），但 `task_index ∈ 12..23`——这些索引从未进入任何前期任务（前期全部使用 `0..11`）。24 个环境 × 2 条估计路线 = 48 条记录。环境是统计单元；路线做配对比较。
- **协议**：完全沿用 FP-CERTFIX-001（前 n 固定计数、每步新批次、δ_k = 0.05/12、K=12、η 网格冻结）。唯一的新成分是 C 臂的判决规则。
- **C 臂的正确性声明（推导要点）**：在证书有效事件 Ω 上，被更新状态 `A_s ≥ LB_s > 0`，不动状态 `A_s = 0`；由性能差恒等式，`v^{π⁺} ≥ v^π` 逐状态成立（不退化），且在能以正概率到达被更新状态的起始状态上严格。声明级别弱于 A/B 的"逐状态严格"——如实报告。
- **假设**：
  - H1：C 臂的总轨迹收益 ≥ A 臂（配对、48 条记录）；若 C < A 则如实报告。
  - H2：C 臂在 A 臂零发出的记录上仍能发出（早停补救的核心检验）。
  - H3：B 臂收益 ≥ A 臂但数据成本 4 倍；C 与 B 的收益差回答"按状态规则能否替代买数据"。
  - H4：三臂均零分量退化（C 臂安全性的直接检验）。
- **主指标**：每条轨迹的总价值增益（终 − 初）、初始次优性闭合比例（`v*` 用策略迭代精确求）、逐状态最差退化（应 ≤ 0）、错误发出数（应 0）、唯一数据量（每记录实际抽取条目数）。步数为辅助描述量。零步与早停环境全部报告，不以幸存者均值代替总体。
- **停止标准**：若收益优势只出现在旧 24 环境的对照复算而新环境上没有，停止扩大主张并报告。
