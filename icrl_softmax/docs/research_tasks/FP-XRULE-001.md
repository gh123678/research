## 研究问题

**按状态的保守更新**与**收紧后的无模型证书**这两件事，是否只在原族（4 状态 / 3 动作 / `GAP_BONUS=0.5`）上成立？在一个**从没有任务用过**的族上，二者各自是否仍然带来收益，且**互不干扰**？

## 环境族（沿用 FP-XFAM-001 的预登记定义，本任务首次真正使用）

- **F1**：6 状态 × 4 动作，`GAP_BONUS = 0.5`，`γ = 0.7`，`R* = 1.5`（值域与 envelope 与原族同口径），mixing ∈ {0.08, 0.5}，`task_index 200..223`。
- **F2**：4 状态 × 3 动作，`GAP_BONUS = 1.0`，`R* = 2.0` → `E = 2 + 0.7·(2/0.3) + 2/0.3 ≈ 13.33`，mixing ∈ {0.2, 0.7}，`task_index 300..323`。

每族 24 环境 × 2 mixing × 2 路线 = **96 条路线记录**。生产者用 `evaluate_fp_xfam_001.run_route` 的两条数组路线（与既有族一一对应；网络路线不在本任务范围）。

## 设计

四个格子共享每一步的认证批次（配对比较）：

| 维度 | 取值 |
|---|---|
| 更新规则 | `conj`（合取门槛，冻结规则）/ `perstate`（按状态保守更新，逐行首通） |
| 证书 | `frozen` / `L12S(f=0.9, p=0.05)` |

`K = 4` 预先冻结（`δ_k = 0.05/4`），每步 `16384` 链 × `64`，`min_visits = 2000`，首访采样。

**按状态规则的可靠性论证（本任务登记）**：逐行更新下 `A_s = Σ_a Δπ_s(a)Q^π(s,a) ≥ LB_s ≥ 0` 对每个状态成立（未更新行 `A_s = 0`，更新行 `LB_s > 0`），由性能差恒等式 `v^{π'}(s0) − v^π(s0) = E[Σ_t γ^t A_{s_t}] ≥ 0` **逐状态**不退化，且在任何被更新状态可达处严格为正。

## 可证伪假设（登记于运行前）

- **H1（强制，两项）**：① 每个族、每个格子的每个发出步**逐分量不退化**；② 每步 `E_Q ≥` 该步实测 `‖Q̂−Q^π‖∞`（0 覆盖违规）。
- **H2（规则效应跨族）**：在两族、两个证书下，`perstate` 的平均总价值增益 **均严格大于** `conj`。
- **H3（证书效应跨规则）**：在两族、两个规则下，`L12S` 的平均总价值增益 **均严格大于** `frozen`；但**幅度预期远小于原族的 `1.37×`**（原族那次是无模型 `L12` 的增益；`L12S` 在迭代里被 `L12` 压过），故登记为"方向为正、幅度不设下限"。
- **H4（无反向交互）**：`perstate|L12S` 在两族上均 `≥` `conj|frozen`。
- **H5（成本，必须与效果同读）**：报告每格每步预算、**单独运行**所需认证数据量、以及**同总成本截断**（把每格截到该族最小格的实际步数后重算发出数与价值）结果。
- **H6（新维度不破坏构造）**：F1（24 个状态-动作对）上四个格子的覆盖违规均为 `0`，即证书与规则对**维度通用**。
