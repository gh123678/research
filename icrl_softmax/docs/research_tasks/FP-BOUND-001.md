## 研究问题

`E_Q` 的保守度里，有多少是**可以不带额外概率代价、或只带已登记代价就取回**的？取回之后，第一步发出数与短轨迹停步各改善多少？

## 诊断（pilot，已在封存数据上完成，用于设定登记带）

在 `results/FP-CERTFIX-001/claude/step1_fv_c64k` 的 48 条记录上逐项重算（脚本 `diagnose_fp_bound_slack.py`，**exploratory，非确认性**）：

| 杠杆 | 均值 `E_Q` | 相对现状 |
|---|---:|---:|
| 现状 | `0.11414` | — |
| **L1** 包络改用已知 `Qhat` | `0.10153` | `−11.1%` |
| **L3** L1 + 精确传播 | `0.07068` | `−38.1%` |
| （参考）L1 + oracle 支撑值域 | `0.09382` | `−17.8%` |
| **L1+L2+L3** | `0.06824` | `−40.2%` |

三个来源，价格不同：

- **L1（无模型，零代价）**：包络 `E = R* + γB + B`（`B = R*/(1−γ) = 5`）是**对一切 `Qhat` 的最坏情况**，但 `Qhat` 是证书的输入、完全已知。故可用
  `E_eff = R* + γ‖V̂‖∞ + ‖Q̂‖∞`，`V̂ = π·Q̂`。
  这是同一命题换一个更小的**真实**值域，不估计任何量、不花任何概率。
- **L2（无模型，零代价）**：MP Thm 4 是**双侧**在 `δ` 成立的，而实现取 `δ' = δ_step/(2d)` 再按"两个方向"记账，实际只花掉 `d·δ' = δ_step/2`。取 `δ' = δ_step/d` 花满预算，`log(2/δ')` 从 `6.87` 降到 `6.17`。
- **L3（需要转移核，须标注）**：`Q̂ − Q^π = (I − γP^π)^{-1} ρ` 是**恒等式**，不是不等式。用逐对的 `ε_x` 做精确传播：
  `w = (I − γK)^{-1} ε̄`，`K(s,s') = Σ_a π(a|s)P(s'|s,a)`，`ε̄(s) = Σ_a π(a|s)ε(s,a)`，
  `E_Q = max_{s,a} [ ε(s,a) + γ Σ_{s'} P(s'|s,a) w(s') ] ≤ max_x ε_x/(1−γ)`。
  收益来源是 `ε` 的**非均匀性**（实测逐对 `max/min` 中位 `4.40`）。这与 oracle 核臂同族（读转移核），**不得**用于"只用行为数据"的声明。

**诊断给出的可证伪预测**（供确认性运行检验）：oracle 支撑值域在 L1 之上只多值约 `7%`，即**值域杠杆基本被 L1 吃完，不需要核**。

## 可证伪假设（预登记，运行前冻结）

确认性运行在**诊断未接触过的 24 个新环境**（`task_index 12..23` × 两种 mixing，48 条记录）上进行，预算 `c16k` 与 `c64k`（65536/16384 条独立链 × 64），目标策略 `π_0`，第一步。

- **H1（正确性，强制）**：四个杠杆的 `E_Q` 在每条记录上 `≥` 实测 `‖Q̂ − Q^π‖∞`（0 违规）；且 `L1+L2+L3` 的 `E_Q` 在**每条记录**上 `≤` 现状 `E_Q`（单调性，0 例外）。任一条不成立即整任务 FAIL。
- **H2（无模型杠杆的量级）**：`L1+L2` 相对现状的降幅落在 **`[−25%, −5%]`**。
- **H3（含 oracle 杠杆的量级）**：`L1+L2+L3` 的降幅落在 **`[−55%, −20%]`**。
- **H4（判决后果）**：在 `c64k` 上第一步发出数**不下降**，且相对同一批的现状臂至少 `+3` 条（48 条中）。
- **H5（短停步）**：把 FP-SHORT-001 口径的 `E_Q/h` 用 `L1+L2+L3` 重算，`c64k` 下中位数降到 `1.0` 以下。
- **H6（值域杠杆被 L1 吃完）**：oracle 支撑值域在 `L1` 之上额外降幅 `≤ 10%`。
- **H7（可加性）**：`L1+L2+L3` 的降幅不低于三个杠杆各自降幅之和的 `80%`（即没有相互抵消）。
