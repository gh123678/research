## 0. 先报告两条候选路的结论（理论，不是实验）

**(a) 非均匀分配 `δ_k`：不可行。** `Σ_k δ_k = δ_total` 约束下，union bound 的花费是 `Σ_k log(1/δ_k)`，它在 `δ_k` 上**严格凸**，故等分是唯一最小值；而证书半径随 `log(1/δ_k)` 单调，最坏步（也就是决定停步的那一步）的半径由 `max_k log(1/δ_k)` 决定，等分同样最小化它。**任何非均匀日程都只能让某一步更差。** 这是个否定结论，登记在案，不再尝试。

**(b) anytime-valid 置信序列（把 `log K` 换成 `log log K`）：在本题参数下反而更差。** 标准正态混合 CS 的边界约
`σ·sqrt((log n + 2 log(1/δ))/n)`，而固定样本 + union 是 `σ·sqrt((2 log K + 2 log(2/δ))/n)`。谁更紧取决于
`log n` 与 `2 log K` 的比较：

```text
本协议：n ≈ 16384 → log n = 9.70；K = 16 → 2 log K = 5.55
```

**CS 多花 4.15 个 log 单位，在这里是明确更差。** 交叉点在 `n ≲ K²` 附近，本协议远离该区间。登记为否定结论。

## 1. 那么真正的杠杆是什么

K 是**保证的一个自由参数**，而实测轨迹长度均值只有 `2.85`、最长 `14`。把 K 诚实地取小，`δ_k` 变大、`log(2/δ_k)` 变小：

| `K` | `log(2d/δ_k)`，`d=12`，`δ_total=0.05` |
|---:|---:|
| `4` | `7.56` |
| `8` | `8.25` |
| `16` | `9.64` |

`K=16 → K=4` 把 `log` 项降 `22%`（`√` 项 `−11%`，线性项 `−22%`）。**这不是"改日程"，而是把保证的承诺范围对准真实轨迹长度**——承诺仍然是严格的，只是承诺对象从"16 步以内"变成"4 步以内"，且必须如实写明。

## 3. 可证伪假设（登记于运行前）

- **H1（强制）**：每个 (臂, K) 格的每个发出步**逐分量不退化**，且每步 `E_Q ≥` 实测 `‖Q̂−Q^π‖∞`。任一例外即 FAIL。
- **H2（K 惩罚的代价）**：平均轨迹长度随 K 减小而增加：`len(K4) > len(K8) > len(K16)`。
- **H3（走到头）**：`L12M(0.05)@K4` 至少有 `15/48` 条轨迹走到 `K=4`。
- **H4（停步的成因）**：把 `L12M(0.05)@K16` 的停步分成两类——`E_Q/h ≤ 1.25`（界驱动的"贴线停"）与 `> 1.25`（改进真的用完）。登记：贴线停占比 **≥ 40%**（若成立，说明界仍是主要机制；若不成立，说明迭代已经被收敛而非界限制）。
- **H5（最终臂的增益）**：`L12M(0.05)@K16` 的总发出步数 `≥` FP-ITER-BOUND-001 中 `L12M(0.5)@K16` 的 `89` 步。
- **H6（K 的收益）**：`L12M(0.05)@K4` 的平均总价值增益 `≥ 1.20 ×` `L12M(0.05)@K16`。
- **H7（不是被截断假象）**：`K=4` 的结论不能只靠"截断更早"获得——报告 `K=4` 下平均长度 `< 3.2` 时同时给出 `K=8/16` 的同口径数字，且 `K=8` 与 `K=16` 的长度差 `< 0.5`（若成立，说明长度确实由 K 决定而非由数据决定）。
