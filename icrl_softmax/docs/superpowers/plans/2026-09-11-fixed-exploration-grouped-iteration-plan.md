用户已确认具体设计并安排 Claude 主执行、GPT 验收。以任务单 v1.1 为唯一
科学协议，不重复征求同一方案确认。writing-plans 技能文件在本机技能和插件
目录中未找到；本计划由 GPT 直接编写，不把缺失的辅助技能当成研究阻塞。

1. GPT 记录分工裁决并发布 REVIEW。Claude 只读预审任务、设计、计划、
   AGENTS.md 和 ACTIVE_WORKSPACE.md；有任务异议立即停止等待用户裁决。
2. APPROVED 后 GPT 保存原始预审记录、发布 ACTIVE 提交，再从该共同
   提交创建 claude/FP-EXPL-001 的隔离工作树。
3. Claude 在授权目录记录执行清单，独立完成采样器、三个计算路线、
   标量有限参考、理论、验证器和报告；严格执行一批 64 条与 64 次更新。
   不改变冻结协议，不写全局 memory，不读写无关文件或其他任务结果。
4. Claude 保留实际失败和普通修复，完成自检、Ruff、原始结果 SHA-256，
   以 [claude] 提交首轮源码/理论/报告，结果继续标为初步结果。
5. GPT 运行独立验收程序，重建种子和全部数学输出，重放 Claude 程序，
   审查矩阵实现和证明。实现错误由 Claude 原作者修复，不改冻结标准。
6. GPT 报告 PASS/FAIL/OBJECTION。Claude 只读复核 GPT 的验收程序和证据，
   在自己目录写复核报告。双方 PASS 且全部验收满足后，GPT 汇总结论、
   更新任务与 ACTIVE_WORKSPACE.md。不得自动合并或推送。

Claude 使用现有本机 Claude Code 与现有后端配置。预审只提供任务所需
文档；执行仅访问自己的隔离工作树和声明文件。无权限时报告原始拒绝，
不得改用另一工具重做被拒绝的操作。每次继续前先检查已有进程，避免重复。

GPT 在等待 Claude 时可以编写基于冻结任务的独立审核计算；正式验收在
Claude 首轮封存后进行。本次不声称两套完整盲态网络独立实现。
