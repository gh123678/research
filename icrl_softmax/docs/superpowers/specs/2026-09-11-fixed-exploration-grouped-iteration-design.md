## 数据和计算过程

    固定均匀行为策略 pi_b
        -> 从初始状态 0 连续采样 64 条转移
        -> 记录四个状态动作对的访问次数
        -> 检查本批是否完整覆盖
        -> 固定这批数据，初始化 Q=0
        -> 直接组内平均 / 精确分组注意力 / 有限 softmax
        -> 各执行 64 次同步更新并比较

目标策略仍为：

    pi = [[0.75, 0.25], [0.25, 0.75]]
    pi_b = [[0.5, 0.5], [0.5, 0.5]]

## 保留的更新公式与网络边界

对访问次数 n_x>0 的状态动作对 x：

    d_t(q) = r_t + gamma sum_a pi(a|s'_t) q(s'_t,a) - q(s_t,a_t)
    F0(q)[x] = q[x] + alpha/n_x sum_{t:x_t=x} d_t(q)

论文的整批访问频率因子不加入本轮公式。网络沿用固定权重的当前值读取、
后继状态读取、TD 残差计算、有限 softmax 写入及固定 scratch 清除。
动态 Q 的读取和写入必须经过声明的注意力矩阵，不能用外部查表替代。
原始环境转移概率只供采样器和独立审计器使用，真实 Q 只供审计。

## 怎样判断结果

先检查两条精确路线一致、有限网络与独立标量公式一致，然后检查误差界。
只有证明有限算子收缩时，才报告其唯一固定点和以下三项分解：

    q_f,k - q_pi
      = (q_f,k - q_f,infinity)
      + (q_f,infinity - q_hat)
      + (q_hat - q_pi)

依次对应有限迭代误差、注意力固定点偏差和固定数据的偏差。
三项向量之和等于总误差；范数之和只是上界。
不满足收缩充分条件时，保留有限步结果与扰动界，不能直接称为发散。
数据偏差仍可能偶然为零；如实报告，不为得到非零误差更换样本。
一批数据无法证明样本复杂度、误差随样本数单调下降或一般策略改进。
